## §Access — transport, parsing
- **CAPTCHA** ("Ich bin kein Roboter") in a browser: wait ~8 s and re-check, most auto-solve. Never hand it to the user early ([[feedback-captcha-wait]]).
- **Full-detail path = the mobile-API JSON, no browser. Transport order (2026-10-27):**
  1. **The prompt names `tmp/eval/{NNN}/is24-api.json`** → the orchestrator pre-fetched it in the main session. Read that file, assert `header.id == scoutId` (top-level `header`, see JSON shape), and **never curl IS24 yourself**. A mismatched or empty file → don't score; ask the orchestrator for a re-fetch in the action line. *Why:* the harness's auto-mode classifier refuses the IS24 API curl inside subagents ("Bot Check Circumvention", #1016/#1017, 2026-10-26/27), even with the allow rule.
  2. **No file named** → curl it yourself, exactly:
     `curl -s --compressed -H "User-Agent: ImmoScout24_1410_35_._" -H "Accept: application/json" -w 'http=%{http_code} size=%{size_download}\n' -o $W/e.json "https://api.mobile.immobilienscout24.de/expose/{scoutId}"`
     **Always this Android UA on the first call; treat any UA quoted in an orchestrator prompt as wrong** (seen ≥5 times, e.g. `ImmoScout24_2.6.1_10.2.1_._`, `…_iPhone/25.0.0`, `ImmoScout_27.3_26.0_._`).
  3. **The curl is refused by the classifier** (it also refused a Firefox-`-A` Kleinanzeigen curl) → don't retry with another UA or rephrase: that works around a denial. Twin fallback: plain curl (default UA) of the Süddeutsche / Ab-ins-Zuhause twins (both 200; AIZ carried Vonovia's full text, cost split, EA, Frei ab) and grep the raw HTML for `immowelt\.de/expose/[0-9a-f-]+`; a Kleinanzeigen twin via WebFetch. Identity = Kaltmiete to the cent + m² + rooms + title. Mark IS24-only fields (liveness, Etage, gallery, priceBar) "unverified" in section 0, make "open the IS24 exposé" next step 1, flag it in the return line. No twin → `NEEDS-BROWSER`. *Why:* otherwise the choice is NEEDS-BROWSER or scoring without naming the source.
- **Five API failure modes; only one means EXPIRED:**
  1. `000` / curl exit 1 / no file = connection reset → retry.
  2. `403` + ~900 B CloudFront HTML = transient edge block of a minor version (`_30_` failed on #510, worked on #549) → retry.
  3. `200` + **0 bytes** = wrong UA family → retry with the Android UA. Never EXPIRED.
  4. `200` + a **complete JSON of a DIFFERENT exposé** (#771–#773: a non-standard UA returned 134897508) → **after every fetch assert `header.id == scoutId`** (and the title vs the prompt hint).
  5. `404` + ~221 B JSON `ERROR_RESOURCE_NOT_FOUND` = gone → EXPIRED (§Expired).
- **Temp files only in your own `tmp/eval/{NNN}/`.** Shared names (`e.json`) were overwritten by siblings (#365, #814, #817, #818, #820: valid JSON, wrong property). If two reads of one file disagree, suspect a collision.
- **Plain curl of the web exposé = HTTP 401 + bot-wall page** whatever the UA. Its text contains "Cookies … deaktiviert", so gate any `/deaktiviert|nicht mehr verfügbar/` test on status 200 AND the absence of "Ich bin kein Roboter".
- **Long TEXT_AREAs are truncated by the API** (#645 cut at 3.887 chars); no description endpoint, web page 401. The cut has always landed in the closing "Highlights" recap: note "tail truncated", **don't escalate to a browser for it.**
- **External sites:** on a WebFetch TLS error, retry curl on the apex without `www` (#633). WebFetch ignores query params on some Amt geoportals.
- **orte address page — run it on every ad with a known street + Hausnr, EXCEPT under a pre-fetched `is24-api.json`:** orte is an IS24 domain, so the "never curl IS24 yourself" rule (transport 1) covers it. Then skip the sweep, date via [[immobilienscout24-history]] §Dating 5/6, and say "orte sweep skipped (pre-fetch mode)" in section 0 (#1045). Whether the orchestrator should pre-fetch the orte page next to `is24-api.json` is an open proposal below. Recipe when allowed: `curl -sL --compressed -A "{Firefox UA}" -H "Accept-Language: de-DE" https://orte.immobilienscout24.de/adresse/{ort}-{plz}-{strasse-slug}-nr-{n}` (WebFetch 403, `atlas.` 301; sweep 3–4 neighbouring numbers when the Hausnr is uncertain). **`-L` is required:** since 2026-10 the short `…-str-nr-{n}` slug answers 308 (~47 KB stub) to the long `…-strasse-nr-{n}` slug, and the grep on the stub finds nothing (#916). It gives:
  - (a) KI-generated building text (grep `erbaut|Wohneinheiten|Stockwerke|Geschätzte Miete`). **The exposé always wins over it**: amenity lines usually echo the ad but not always (#944 "keinen Aufzug und keinen Keller" vs `obj_cellar: y` + "eigener Kellerraum" → at most a "confirm at viewing" note), and Baujahr/WE can be flatly wrong on Denkmal conversions (#915 Voltaireweg 6: "modernes Reihenhaus seit 2010, 1 WE" for the 1879 Garde-Ulanen stable with 13 flats; it would have moved the Mietspiegel row from bis-1948 to 2009–2012).
  - (b) JSON of **live exposés at or near that address, Kauf and Miete side by side**, with `@creation`/`@publishDate`/`@modification` (ad date: [[immobilienscout24-history]] §Dating; parallel sale: §Anbieter). *Why:* #907's rental exposé gave no hint that the flat was also for sale.
  - **The ID set can be a nearby-listings widget, not per-address:** on #919 (Neuendorfer Anger 5/6/7) all three pages carried the same 16 IDs. Check each hit's own street + Hausnr (or that the set differs between neighbouring numbers) before reading "also for sale" or a dup out of it.
  - **Exposés with `obj_street: no_information` are absent from it**, even when their text names street + Hausnr (#915). An empty sweep then neither proves the ad dead nor dates it; fall back to media-ID/PDF dating ([[immobilienscout24-history]] §Dating).

### JSON shape (top-level `header` + `.sections[]` by `.type`)
- **`header` is a TOP-LEVEL key (`d.get('header')`), not a section**: a sections-only lookup returns None and the `header.id` assert + liveness read silently fail (#934). Fields: `id`, `publicationState` (`active`/`live` = live), `realEstateType` (`apartmentrent`, `houserent`, `housebuy`, `livingbuysite`), `isTenantNetwork`, `shareMessage`. **`header` can be absent** (#320): read liveness from the `FRAUD_REPORT` URL's `publicationState=` param.
- `TITLE`, `MAP` (addressLine1/2, lat/lng, zipCodeShapes), `TOP_ATTRIBUTES` (Kaltmiete/Zimmer/Wohnfläche/Warmmiete, `REDUCED_PRICE`), `TAG_LIST`, `PRICE_INFO` (priceBar), `PRICE_RATING`, `FINANCE_COSTS`, `TRAVELTIME` (`isBlocked`), `RELOCATION`, `REFERENCE_LIST` (Preisentwicklung link, "Weitere Dokumente" PDFs, project pages), `AGENTS_INFO` (company, name, title, rating, `verifiedBy`, phoneNumbers, Impressum in `references[].url` `is24://imprint?text=`), `OBJECT_INFO` ("Scout-ID … | Objekt-Nr. …"), `contact` (`freemiumSettings`, `mailButtonState`, `callButtonState`).
- `ATTRIBUTE_LIST` ("Hauptkriterien" / "Kosten" / "Bausubstanz & Energieausweis"): `{label,text}` or `{type:"CHECK",label}` = present. "Energieausweis: liegt vor" often comes without class/value (a Low signal).
- `TEXT_AREA`: Objektbeschreibung / Ausstattung / Lage / Sonstiges; any can be missing, a private ad can have none (#681).
- `MEDIA`: [[immobilienscout24-media]] §Photos. The top-level **`adTargetingParameters` (~51 keys) is the full field mask**; `tracking.parameters` is a stripped ~18-key blob (§Mask).
- Parse with python3 `json.load`. **At least one section is an empty `{}` with no `type`**, so use `s.get('type')`. `AGENTS_INFO.rating` can be missing = no reviews (H ≈ 3,5 unknown), not a negative. Several `ATTRIBUTE_LIST`/`TEXT_AREA`/`REFERENCE_LIST` entries exist: key them by `title`.
- **CiC-only quirks** (web page fallback): the redactor turns zero-padded dates (`01.08.2026`, Vonovia `DD.MM.YY`) into `[BLOCKED: JWT token]`; match `/(\d{1,2})\.(\d{1,2})\.(\d{2,4})/` on `textContent`, else split in-page and return the parts. Scope keyword tests to `.is24qa-objektbeschreibung`/`-ausstattung-beschreibung`/`-lage`, **never `document.body`**: page chrome and the "Weitere Einheiten" sidebar fake Keller/Garten (`\bGarten(?!haus)`), **WBS** (#264: a sibling's "WBS 140") and **möbliert/auf Zeit** (#265) hits, so anchor blockers on this unit's h1 + text. Tenant-network pages have no `<dl>`: read `body.innerText`.

## §Expired — EXPIRED detection and special live states
- **Mobile API 404 `ERROR_RESOURCE_NOT_FOUND`** = gone → EXPIRED. Before filing, run a **control curl** on a known-live exposé with the same UA (#371). *Why:* otherwise an API/UA change mislabels a whole batch.
- **Web "deaktiviert" stub**: HTTP 200 with h1/coarse address/m², all criteria null, "Vor N Tagen deaktiviert" / "Angebot wurde deaktiviert" / "Dieses Angebot ist nicht mehr verfügbar". Match `/deaktiviert|nicht mehr verf[üu]gbar/i` ("nicht gefunden" misses it) → EXPIRED, don't score the stub (#259, #260). Mind the bot-wall false match (§Access).
- **After a 404, rescue the text from `mapio.net/expose/{id}/`** (WebSearch `"{Straße} {Ort} {Objekttyp} mieten"`; curl works): full description/Ausstattung/Sonstiges/Anbieter + the posting date, which separates "let" from "bait withdrawn". See [[mapio-net]] (#733).
- **Stub exposé** (title `"s"`, description `"t"`, 0 photos, `publicationState: live`, full criteria, named private Anbieter; #349): not EXPIRED, not a glitch. Score from the criteria: D cap 3,0, must-haves unconfirmed, H 2,5, "Proceed with Caution".
- **Preview / not yet published** (200, "Adresse … erst nach Veröffentlichung", Anbieter hidden, "Bald verfügbar", 0 photos, criteria populated; #277): score it (D cap, H low); next step = wait for publication. A "Fotocasa" string is a syndication artefact.

## §Tenant — Mieternetzwerk (tenant-posted) and private Nachmieter ads
Normal permanent rentals, not swaps ([[project-nachvermietung-not-filtered]]). **Exception:** a Suche line in the description tail ("Wir suchen eine 3-4 Zi Wohnung in …") makes it a swap → two-sided match (#340).
- **Detect:** `header.isTenantNetwork: true`. Corroborators: `TAG_LIST` id `TENANT_NETWORK` ("Nachvermietung ab {Monat}"), `AGENTS_INFO.title` "Aktuelle:r Mieter:in", the vorgeschlagen/Mietanpassung/Möbelübernahme notice. You are only *proposed* to the landlord → H ~3,0. Flag Möbelübernahme; drop it when the photos show an empty flat.
- **Only `obj_totalRent` (warm) is real.** IS24 back-computes `obj_baseRent` = **exactly 70 %** of it, with ±5 % bands ("Geschätzte Kalt- und Warmmiete"). Always compute the ratio. At 0,70 Kalt and NK are arithmetic: no Kaution-legality check, ask for the split (#552, #561, #612, #615). **The error has no fixed sign; it follows the local NK level.** Normal stock understates Kalt (#935 = #747 re-posted as a plain private ad: real 850/200 vs derived 735/315 at warm 1.050; the re-post also hardened the Bezug from "ab Dezember" to "Bedingung 01.11." — re-read a twin's dates too). High-NK Fernwärme stock OVERSTATES it: Kirchsteigfeld Vonovia NK+HK 4,6–5,3 EUR/m² (#353: 5,09) gave #1028 ~656–706 vs derived 770,70, #1030 ~834 vs 867,30. Never apply a fixed factor: reconstruct `totalRent − NK/m² × m²` from the best NK tier as a band, test that against the caps and the Mietspiegel. *Why:* a blind "+15–20 %" would have put #1028 near the Bremse limit and #1030 at a false Bremse breach.
- **The search-card / pipeline price is NOT a Kaltmiete:** it is the TOP of the ±5 % band = 1,05 × 0,70 × `obj_totalRent` (#1020: 1.520 = 1.446,90 × 1,05; #1029: 588 at warm 800). Write the reconstructed Kalt (`~`) in the tracker. `card ÷ 0,735` recovers the warm rent of an expired, unscored tenant ad from its scan-history row (#268: 589,89 → ~802,57) for the warm-to-the-euro identity check ([[immobilienscout24-history]] §Identity). Lead A with warm vs `max_warmmiete` (#676: derived 1.610 fit, reconstructed 1.920–2.050 broke all three caps). **NK evidence ranking:** stated split (a twin ad) > same-building rate from a sibling report > city band 3,00–4,50 incl. Heizung; name the tier (#694 derived 5,35 vs #761 stated 4,65).
- **"Die Miete wird sich eventuell anpassen" → quantify the re-let:** `m² × sibling ask + NK` against both caps; best anchor = a same-street landlord ad in `data/listings.md`, `reports/` **or `data/pipeline.md`** (#745 → still inside the caps, A 4,5). **Score A on the position within the Mietspiegel Spanne, not budget headroom** (#735 at the Unterwert = 5,0 vs #746 at the Oberwert = 4,5); only an under-Spanne rent has a legal ceiling absorbing the increase. Below the Ortsteil level = the old contract, not a bargain or scam signal (#614). **Above it** (#747) flips the re-let into an opportunity (§ 556e only carries the Vormiete forward): −0,5 Mietspiegel, −0,5 over its Ortsteil. In a **post-2014 quarter (§ 556f)** there is no ceiling, so the sibling gap IS the re-let number: −0,5, ask "bleibt die Kaltmiete?" first, and call § 556f an assumption while the Baujahr is unstated (#693).
- **Dates:** TAG_LIST month vs description date → take whichever is still future (both future → the description). Never score F off a past date (#560, #554). Both past on an active ad (#553, #562) → F 3,5, staleness signal, "still free?" as next step 1, not EXPIRED.
- **Title and description are IS24-generated from the form** ("Wohnen mit Charakter: 3-Zimmer-Wohnung in Potsdam"): an identical title is **zero** dup evidence (#736/#619, #768 vs #216), and title rooms/city can be wrong (#562 "1-Zimmer" for 3,5 Zi; #557 "Brandenburg an der Havel" for Bornim). Use `obj_noRooms` and the geo cluster; title + text agreeing is one field printed twice; the floskel is not a scam tell. Prose m² vs `obj_livingSpace`: the field wins, ask (#559). A one-sentence text can be the key fact ("Wir dürfen keine Nachmieter suchen", #614 → G 3,5, H 3,0).
- **Address resolution order:** (1) the description opening ("Diese Wohnung in der Peter-Behrens-Straße", #768) or a title that is only "Stormstraße 16" (#737), checked against `geo_ot`/PLZ; (2) the Telekom base64 leak (§Location); (3) PLZ only. The trio `TRAVELTIME.isBlocked` + addressLine1 "…erhältst du vom Anbieter" + `grep -c telekomInternetUrlAddition` = 0 → **unrecoverable, stop hunting** (#612, #618, #620): bracket the Mietspiegel over the plausible Baualtersklassen ("nicht bestimmbar") and anchor on evaluated Ortsteil comparables.
- **With a street:** `grep -ri "{Straße}" data/listings.md data/pipeline.md reports/` → Baujahr, Verwalter, NK rate, house ask, amenity priors (#559 → #293/#361); a same-street report outranks KI text. **Without a report:** WebSearch `"{Straße} {Nr}" {PLZ} {Ort} Baujahr Energieausweis` (#561: presumed Platte = Neubau 2021 EEK B, a 2,7× swing) and/or the orte page (§Access).
- A decoded address that is a special building (#557 = AWO Gemeinschaftsunterkunft) → data-integrity flag + contact Q1, not scam. **Unresolvable same-building dedup** (UUID, Immowelt sibling = curl 403) → score as new with an "open identity question" section (#738 vs #666; keys in [[immobilienscout24-history]] §Identity).
- **Plain private Nachmietergesuch / private landlord ad** (`isTenantNetwork: false`, `obj_privateOffer: true`): real Kosten list, untouched mask (§Mask). `obj_baseRent` is the outgoing tenant's rent; the new rent may be only in prose (§Price). "Herr {Vorname} {Initial}", empty address, no phone → unresearchable, H ≈ 2,5 (§Anbieter).
- **Nachmieter as Eintritt in den bestehenden Mietvertrag** ("tritt in die bestehende vertragliche Mietregelung ein"): Vermieter unnamed → H ~2,5. No new contract → § 556d doesn't apply (ask whether a new one will be signed, which flips it). Next step 1: the contract + Nachträge. "Umzug ins Ausland zum {future date}" is not the "landlord abroad" signal.

## §Price — price fields and anchors
- **Ratio test `obj_baseRent / obj_totalRent` on every ad.** 0,70 = back-computed (§Tenant). **1,00 = no Warmmiete at all**: an empty NK field makes IS24 echo the Kalt as "Gesamtmiete"/"Warmmiete" while the row still says "Kaltmiete (zzgl. Nebenkosten)". Report warm as unknown + a band (2,50–3,00 EUR/m² incl. Heizung for older stock) against `max_warmmiete` (#713). Exact figures sit in `adTargetingParameters` when TOP_ATTRIBUTES shows ranges.
- **`PRICE_INFO.priceBar`** (similar band, overall band, `priceIndicatorPositionInPercent`) = the address-precise scam-price check. **On an address-less tenant/private ad it is NOT building-precise:** such ads sit at ~7–10 EUR/m² everywhere in Potsdam (#1023 Nedlitzer Str. 7,00–9,70 vs the dated Esplanade exposés on the SAME geocode #917/#918 10,30–16,10; #877, #880, #882). Never infer building age from it or refute a same-building match with it; it keeps only its scam role (offer below `minSimilarPrice`). It can be missing (#552): use the Mietspiegel bracket + the Ortsteil anchor ([[potsdam-mietspiegel]]); without a band the "20 % below" High can't fire. **`PRICE_RATING` "Geprüfte Miete"/`FAIR_OFFER` is IS24's badge, not Bremse evidence** (#616: FAIR_OFFER at position 0,88).
- **Percentile vs Mietspiegel:** the band is Ortsteil-wide, so a building younger than its Ortsteil tops it without being overpriced (#561: 0,93 yet 26 % under its correct field). For A/Bremse the Baualters-correct field wins; the priceBar governs only scam signals. **Converse:** typical/old building + above band + over Mietspiegel = a real overshoot → one step below the usual 4,5 (#625 → 4,0). A tenant ad above the band = "Bremse probably breached".
- **`REDUCED_PRICE` (`originalPrice`/`text`): divide the Kaution by BOTH.** It is often still 3× the OLD rent (#512 3,27×, #757 3,11×) → **G 2,0 categorically**, mitigation in prose; a re-derived one is legal (#740). The cut is evidence the old ask wasn't enforceable. **Contractual temporary cut** ("Einstiegsmiete", a "Besondere Mietkondition:" block in **Lage**; #569 steps up +645 EUR after the Schallschutz defects are fixed): grep Lage + Objektbeschreibung for `Einstiegsmiete|temporär|Mietreduzierung|Mietminderung|erhöht sich|Sonderkündigungsrecht`. Score A on `originalPrice` with a now/later table, D down for the named defect, G ~2,5.
- **Private Nachmietergesuch: `obj_baseRent` is the outgoing rent.** Grep `Aufschlag|Anpassung|Erhöhung|erhöht sich|Neuabschluss|Neuvermietung` and re-run caps/€/m²/Mietspiegel/Kaution on the announced figure (#568 +200 → warm cap breached, A 5,0 → 3,5).
- **"Warmmiete" without heating:** `Heizkosten` 0/missing + "Heizkosten in Nebenkosten enthalten: Nein"; `Etagenheizung` / `obj_heatingType: self_contained_central_heating` alone suffices (tenant holds the gas contract; #532, #567). Report the printed figure + a labelled all-in: with an EA `Endenergie × m² × ~0,11 EUR/kWh ÷ 12 + ~15`; without, 12–18 EUR/m²/year for Altbau. Test it against `max_warmmiete`; ask for the last two Gasabrechnungen. **Mirror:** `obj_totalRent` > Kalt+NK+HK by >±4 EUR = an unitemized position: prove it by diffing a same-landlord sibling (#691 +54,70 vs 0/−4,20), use the higher figure, ask which position (Low flag, not scam).
- **"Nebenkosten" field > Kaltmiete = the lister typed Kalt + Betriebskosten into it** (#875: KM 1.832,93, "Nebenkosten" 2.199,52, Gesamt 2.295,99). Test: Gesamt − field = Heizkosten (96,47 = 1,00 EUR/m² × 96,47 m²), field − Kalt = BK (3,80 EUR/m²); a round per-m² result confirms it. Report the split as a data-entry quirk, not padding. *Why:* read literally, NK = 22,80 EUR/m².
- **Project cards quote another unit's price.** A hit titled "{N} passende Wohneinheit(en): {Projektname}…" is an IS24 *project* card (`obj_projectId` set) with the project's "ab"/other-unit figure (#916: card 1.290, unit exposé 1.720 kalt). Score the live exposé, name the card price, ask "is the 1.290 unit still free?". *Why:* scoring the card would have passed the 18 EUR/m² cap at 14,5 instead of 19,38.
- **Stellplatz in or out of the Gesamtmiete varies per ad of the SAME landlord** (K&D: #1035 Kalt + NK = Gesamt, Stellplatz 100 on top; #1048 Kalt + NK + 100 = Gesamt). Always compute Gesamt − Kalt − NK against "Preis pro Parkfläche" before testing `max_warmmiete`. *Why:* assuming the #1035 pattern would have put #1048 at 2.260,56, over the cap.
- **Kaution ÷ 3 = Kalt** resolves Kalt vs Teilwarm and which of two conflicting ads is consistent.
- **Wohnfläche with Freisitze at 100 %** (#751 plan "Balkon (100 %)") breaks WoFlV (max 50 %, usually 25 %): compute €/m² on the honest area. Below BGH 10 % it's leverage, not a claim.
- **"Energieausweis: laut Gesetz nicht erforderlich" on a rental** (Denkmal in text only, or pre-1948 in a Denkmalbereich): the Potsdam Mietspiegel **`kein EA` row** is operative, the A/B row the landlord's best case (#582, #638). See [[immobilienscout24-kauf]] K2.
- **Havelland rents 2026:** Dallgow flats ~11,8–14,7 EUR/m², **houses ~100 m² ~18,95** (judge a Haus on the house anchor). **Mietpreisbremse in Havelland only in Falkensee, Brieselang, Schönwalde-Glien**: Dallgow = not applicable, no § 556g lever (#530).

## §Mask — amenity flags (`obj_*`): when is `n` a fact?
- **Read `adTargetingParameters` (~51 keys), never `tracking.parameters` (~18 keys, no amenities)** (#619/#622/#623). A "missing key" means the wrong blob.
- **Untouched mask** = all flags `n`, zero positives, condition/interiorQual/pets = `no_information` (all tenant ads, most private ads). Every `n` is **unset, not absent**: score amenities from text/photos/plan, never fire "2+ must-haves missing = 1,0", make them contact Q1 (#504 `obj_balcony=n` vs "• Balkon"). **E:** no photo and silent text → 2,0 (#622); ≥1 real photo → 2,5 (#559); one must-have granted + one unconfirmed → 3,0 (#635, #741).
- **A deliberate `n` needs ≥2 `y`/CHECK positives on a commercial ad** (a real `obj_condition` alone isn't enough; #530) **and no other `n` refuted by text or title**: one refuted `n` voids the whole mask (#752 EBK itemised vs `n`; #756 title "neuer Einbauküche und eigenem Garten" vs `n`/`n`). The title can only refute, never confirm. With a curated mask a lone `obj_cellar=n` = missing (soften ~0,5 on a Neubau; #523). Absent-with-silent-text needs a corroborator (a second datasheet, a substitute like "Dachboden").
- **`n` + text grants it under a separate contract** ("separater Pachtvertrag" garden #525, Stellplatz "gegen Aufpreis", Keller "anmietbar") = met with a cost caveat, terms in G (Golm Gartenpflege history makes an unclear Pacht a live risk).
- `obj_balcony: n` + Ausstattung "Ausrichtung Freisitz: {West…}" = Wintergarten/Loggia → must-have met (#678, ask whether glazed). `need_of_renovation` + a CHECK = exists, not working (#511 half-dismantled EBK): open the Küche/Bad photos, write "who completes it, by when". `maisonette` + "Etage N von N" = Dachschrägen probably inside the m², internal stair, no lift (#536).
- **Souterrain** (`half_basement`, #631): `obj_cellar: n` is REAL (Keller fails). C −0,5 (Aufenthaltsraum share unknown), Spanne toward the **Unterwert**. "Wohnung/Archiv/Studio" = Wohnraum or Gewerbe? (G question).
- `RELOCATION` links' `floor=0` = unset, not EG.
- **`houserent` masks carry NO `obj_balcony` / `obj_garden` / terrace key** (#967: 51 keys incl. `obj_cellar`, `obj_hasKitchen`, `obj_barrierFree`, `obj_lotArea`): Balkon/Terrasse/Garten on a house rental come only from text, photos or plan; `obj_lotArea` is a garden prior, not a let garden. *Why:* "key absent" read as `n` fires a false missing must-have; `obj_lotArea` read as a garden credits one that may not come with the house.

## §Size — m² and rooms (Block C): validate the typed fields
- **m² typo test (tenant/private typed fields):** EUR/m² = Kalt/m², NK/m² = (warm−Kalt)/m². **NK < ~2,00 EUR/m² indicts the m² denominator.** Test digit slips (180→80) against a real Mietspiegel band (#555: 4,67 EUR/m² at 180 vs 10,50 at 80). Carry the ambiguity in C (#555 C 3,5); never substitute your hypothesis or fire "20 % below Mietspiegel" on it; "Wohnfläche laut Mietvertrag?" = contact Q1.
- **One-directional:** high NK/m² with a normal Kalt/m² indicts the NUMERATOR (bundled Stellplatz/Strom/Möbel or padded Vorauszahlung, #621 5,79): a cost question, not an m² doubt.
- **m²/Zimmer too LOW with normal NK/m² → suspect `obj_noRooms`** (#675 70 m²/5 Zi): C ~4,0, "tatsächliche Zimmerzahl + Grundriss?" as Q1. Very low ratio + Laubengang → "Sonderwohnungsbau?" data flag, not scam. >40 m²/room on a plain flat is also a red flag.
- **Aspirational room count:** a private owner enters rooms the flat *could* have (#754 "4 Zi" vs "auf Wunsch in zwei Zimmer teilen", `Schlafzimmer: 3` vs "zwei Schlafzimmer", plan shows 3). Grep `teilen|teilbar|abtrennen|Trennwand|auf Wunsch`, count plan labels, score the visible count (header + tracker `rooms`).
- **The Grundriss is the referee on documented ads too:** door marks refute "alle Zimmer über den Flur" (#749: Küche + Zimmer 4 only through Zimmer 1). **IS24 `Badezimmer: 2` includes the Gäste-WC**: check the plan before writing "two bathrooms".
- **The headline Wohnfläche can include the Balkonanteil (25–50 %) or Wohn- + Nutzfläche.** The plan title block ("WOHNUNG 8 · 75,12 m² · inkl. Balkon 78,45 m²", #585) or room label ("Balkon A: 10,19 m² / 50 %: 5,10 m²", #587) gives both. **Always sum the room schedule**: it can shift the Mietspiegel column and **flip `max_price_per_m2`** (#587: 17,50 advertised, 18,57 on the interior → over the cap). Score A on the real one, name both.
- **Typed Haustyp can be the whole building when only half is let:** private houserent "Einfamilienhaus (freistehend)" on a Denkmal Kolonistenhaus the Denkmalliste calls a Doppelhaus with 2 WE (#967 Alt Nowawes 103). Weavers'/colonist houses in Nowawes are double houses: on any whole-house ad there ask "whole building or one half?".
- **Over-`max_m2` calibration** (the rubric only defines "under"): +25 % → C 3,0 (#744 150 m²), +50 % → C 2,5–3,0 (#555). Score the residual harm (NK, heating, furnishing); don't mirror the under-size penalty, A already carries the cost.

## §Lease — lease terms and hard blockers hidden in free text
- **No field exists for Staffel/Index/Mindestmietdauer/Kündigungsausschluss.** They sit in Sonstiges, the Objektbeschreibung tail or even **Ausstattung** (#752 Covivio "Indexmietenvereinbarung über 10 Jahre"; #564; #611). Grep **all TEXT_AREAs concatenated** for `Staffel|Index|Mindestmietdauer|Mindestlaufzeit|Mindestmietzeit|Kündigungsausschluss|Mietanpassung`: Index ~−1,0 in A (the whole A risk on a § 556f Neubau), Mindestmietdauer ~−1,0 in G; Staffel amounts are rarely given, ask. *Why:* otherwise G = 5,0 on a locked lease.
- **"Zwischenvermietung bleibt vorbehalten" is Freibleibend boilerplate**, not a Zwischenmiete (#611). **`genossenschaft` always hits** via the "Kaution oder Genossenschaftsanteile" label (#627, #536). Absent `WBS|Wohnberechtigung` IS a reliable negative; market €/m² is almost never WBS stock.
- **Mass-generated exposés (ZBVV etc.): structured fields beat the prose** (#627: text "ab 01. August" vs field 16.09; a "Küche" photo vs `obj_hasKitchen: n`). Contradictions → contact questions, not scam signals.
- **möbliert/auf Zeit exist only in free text** (`realEstateType` stays `apartmentrent`; #647 Progenea). Grep TITLE + all text for `möbliert|auf Zeit|Mindestmietzeit|Höchstmietdauer|befristet|Untermiete|Zwischenmiete|serviced|all.?inclusive|furnished|vorerst|\d+ Jahre`. **A hit is not the verdict.** "teilmöbliert" is usually Möbelübernahme (#701). Cap ≤2,0 only with a real auf-Zeit marker (befristet/Zwischen-/Untermiete/Mietende, a Pauschalmiete without a Kalt/NK split, a hotel-style inventory: Kofferablage, Hosenbügler, rolled guest towels, "Welcome" decor). Counter-signs: a clean split, **Kaution exactly 3,00 NKM**, a concrete Bezug, Keller/Stellplatz. If not capped: "§ 535 or § 549 Abs. 2 Nr. 1?" in G, and **remove the Möblierungszuschlag (~100–150 EUR partial) before the Mietspiegel check**.
  - **A re-list can launder the term into "bezüglich der Mietdauer sind individuelle Absprachen möglich"** (#876 = #126, ohne-makler private flat: "auf Zeit" left the title, "1–12 Monate" became that phrase). That phrase is an OPEN term, never unbefristet: carry the predecessor's term forward, decide from the gallery; Kaution < 3 NKM corroborates. *Why:* read alone, #876 would have been scored uncapped.
  - **Any lease that ends = G 1,0 hard blocker, cap 2,0** (`_shared.md` Block G since 2026-10-21), whatever the length or furnishing: a pure Höchstmietdauer (#748 "24 Monate maximale Mietdauer"), a multi-year term on a teilmöbliert house (#966 Weberhaus-DHH, Sonstiges only "vorerst für 6 Jahre mit der Option auf Verlängerung"; H down for the planned-return horizon; ask § 575 reason vs a >4-year Kündigungsverzicht, invalid in a Formularvertrag), #888 (1+1 J. furnished) and its re-list #978 (3 J. + Verlängerungsoption at the owner's discretion). *Why:* #978 was scored 4,1 uncapped; Mario 2026-10-21: "A 3 year fixed term which ends is not ok."
  - **Not a Befristung:** a Mindestmietdauer / Kündigungsverzicht on an unbefristet lease ("mindestens 3 Jahre"): score normally, state it as a con in the Summary. **§ 575 BGB** is next step 1 on a Befristung (no written reason = unbefristet; quantify the swing); it is also an Eigenbedarf hint → cap H.
- **WG-only "whole flat" ads hide the blocker in Sonstiges only** (#942 Ribbeckstr. 48: card, TOP_ATTRIBUTES and Kosten read as a normal 780 EUR / 75 m² / 3 Zi rental; Sonstiges: "ausschließlich als Wohngemeinschaft mit separaten Mietverträgen … Vermietung der gesamten Wohnung als Einheit ist nicht vorgesehen", "vorübergehender Wohnbedarf"). Cheap tells: `Hauptkriterien` CHECK "WG-geeignet:", `Schlafzimmer` == `obj_noRooms`, `obj_typeOfFlat: other`; on any of them grep all TEXT_AREAs for `Wohngemeinschaft|einzeln(en)? vermietet|separaten Mietverträgen|als Einheit|vorübergehende[nr]? Wohnbedarf`. A hit = G 1,0 hard blocker (cap 2,0, Discarded; same family as Kleinanzeigen #547). *Why:* headline and price fields give no hint.
- **"Einliegerwohnung" → § 573a BGB check** (#1019 Golm, Mieternetzwerk): in a building with ≤2 flats where the Vermieter lives, he can terminate without berechtigtes Interesse (notice +3 months). Not a Befristung, no cap: G ~3,0, H ~2,5, ask "lives the Vermieter in the house / how many WE?". The Mietspiegel is a lower bound only (EFH/ZFH), so a Bremse finding is weak. *Why:* the mask has no field for it.
- **Kaution field is free text** ("3-fache Miete": 3× Kalt legal vs 3× Gesamt illegal): flag the ambiguity in G. **An outsized Kaution** (#854: 18.000 on 1.650 = 10,9 NKM, anonymous 0-photo private ad) is the advance-fee payload; `_shared.md` has no such signal, so override to "Proceed with Caution" explicitly (proposal below).
- **Plural title + generic text** ("möblierte LUXUS Apartments") = a portfolio ad → Musterwohnung viewing question.
- **Neubau pre-letting with only a Sonstiges application boilerplate** (locals Real Estate "Wohnen am Brauhausberg" #624/#628/#629): contract terms are ABSENT, not "none" → G ~4,5, never 5,0; the **Immowelt twin** listed "Mindestmietdauer 24 Monate" as a field → G ~4,1. Nice-to-haves not credited; H ≤ ~4,2 (Vermieter unnamed). The TITLE carries Etage/rooms/orientation. "EA liegt zur Besichtigung vor" = normal here (Low, no EEK bonus). Objekt-Nr. `H{Haus}-{Etage}-{Whg}` decodes the unit; show siblings' €/m². Bauverzug risk in F (~4,3), "kündigen only after a written date". Landing page in REFERENCE_LIST "Weitere Links".

## §Location — which channel to believe (Block B)
- **Search-result Ortsteil is an IS24 label, not a PLZ proof** (#649 "Grunewald" was Halensee 10711). On PLZ-scoped searches verify the PLZ from the live exposé.
- **Geo-tag can name a different MUNICIPALITY** (Makler reach optimisation): #389 tagged Fahrland/Potsdam, both TEXT_AREAs "Wustermark OT Buchow-Karpzow"; #214 (ohne-makler feed) tagged Groß Glienicke, was Eichwalde. Always read the first line of Objektbeschreibung + Lage. A not-listed but not-excluded Gemeinde is no blocker: B down, "Gemeindezugehörigkeit?" as next step 1, score stated at the advertised location. Disclosing the true Ort in the text is exculpatory.
- **`obj_telekomInternetUrlAddition` (base64) leaks a withheld address** (`MAP` "Die vollständige Adresse … vom Anbieter", `obj_street: no_information`):
  `echo "$val" | python3 -c "import sys,base64,urllib.parse;print(base64.b64decode(urllib.parse.unquote(sys.stdin.read().strip())).decode('latin-1'))"` → `{"ort":…,"strasse":…,"hausnummer":…,"plz":…}`. **Decode as latin-1** (UTF-8 fails on umlauts, #376). It can be truncated mid-base64: decode what you can, corroborate with MEDIA/PDF filenames (`OZS020_Energieausweis` = ObstZüchterStr. 20). It is the broadband check-point the lister typed, so report it as an Anbieter-entered hint; on a boundary property it can back the geo-tag rather than the truth (#389). **It loses to the TEXT_AREAs.** A downloaded facade photo can verify it on private ads. Absent on many tenant ads (§Tenant).
- **The Lage TEXT_AREA can be IS24-generated boilerplate** naming a wrong Ortsteil and non-existent transit (#568 "Nauener Vorstadt … S7" for Bornstedt; #854 "S7" for Bornim; #883 for Brandenburger Vorstadt; the S7 ends at Potsdam Hbf). Tell: short, generic, no street/landmark, contradicts title/description. Take the majority of independent channels (MAP, `geo_ot`/`obj_regio3/4`, Telekom, title, description); never credit a transit line named only in generated prose. **But the generator reads the hidden address field, so it can leak a withheld STREET** (#954 private ad, no Telekom leak: "Die Friedrich-Ebert-Straße liegt in der Potsdamer Nauener Vorstadt …"): take it as a street-level hint (no Hausnr) when it agrees with `geo_ot`/PLZ, keep ignoring its transit claims. *Why:* without it the address hunt stops at PLZ. Same generator family: "Etage: N von M" with M ≫ N on `obj_typeOfFlat: roof_storey` (#954 "2 von 6" for a DG) is a typed slip, not a 6-storey building: ask.
- **When free text names a STREET, resolve the Ortsteil via a street directory** (`WebSearch "\"{Straße}\" {Stadt} {PLZ}"`). `MAP.addressLine2` and the `REFERENCE_LIST` "Preisentwicklung" geocode slug are PLZ-derived guesses that can disagree with each other and the truth (#613 Julius-Posener-Str. = Waldstadt I, not Schlaatz/Teltower Vorstadt); the Preisentwicklung link is a price REGION (#741). The street's naming date brackets the Baujahr; "verkehrsberuhigter Bereich" suggests a 2000s+ layout.
- **Konzern boilerplate: Objektbeschreibung, Lage AND Ausstattung can describe a different project** (BUWOG/Vonovia, #510 Brunnenallee 3A: Bornstedt/Tram 92/96 text for a Brunnenviertel flat with Bhf Rehbrücke + Tram 91). The address fields decide (`MAP`, lat/lng, `RELOCATION`/`REFERENCE_LIST` deep-link params, the `geocodes=` path), then WebSearch the street. The BUWOG Ausstattung string mixes building tokens (`Spielplatz`, `Mehrfamilienhaus`, `Fahrradabstellraum`) with unit tokens (`Badewanne eingemauert`) = project spec; **the photo decides each unit-level amenity** (#692 shower only, #691 tub + shower). A data-quality ✗, not a scam signal.
- **`obj_street: no_information`**: read the Grundriss image captions; they can carry the Makler's internal key (`90864 Objekt Hege16 EG` → Hausnr 16, "Hege…"; #706). MEDIA captions on Kauf ads can leak the street too.
- **`obj_telekomInternetSpeed` (address-precise Mbit/s) is a scoreable Block-B negative.** ≤16 Mbit/s → B −0,3 + "check Vodafone Kabel / DNS:NET / Glasfaser for the address" before the viewing (#565: 6 Mbit/s in a prime location; Mario works from home). ≥50 is unremarkable. `obj_telekomInternetAvailable: false` is a real con too.

## §Anbieter — Block H and scam context
- **`contact.freemiumSettings`** (mostly private, also commercial — #972 Hausverwaltung): `dateStarted`/`dateEnding`/`freemiumPeriodActive` = a 48/72/96-h free contact window (read `duration`); `dateStarted` ≈ (re)publication day. It is every private landlord's default, so it counts as **Medium** "new account, minimal profile" (+ H ~1,5–2,5) only with the full cluster: window opened today + `verifiedBy: []` + empty `phoneNumbers` / call button `inactive` + no address + first-name-initial ("Dominic H.") + thin attributes. #625 had freemium but a real mobile, full address, EA and legal Kaution → Low, Legitimate. On a commercial ad with a full Impressum it is no signal. Put an active `dateEnding` in next steps as a deadline. ⚠ **`freemiumPeriodActive: false` with a past `dateEnding` ≠ dead or uncontactable**: check `publicationState` + `contact.mailButtonState: active`; never write a passed deadline; `dateStarted` is then the RE-publication date (#760 → recycled ad).
- **The EMPTY private exposé** (`picturecount 0`, no TEXT_AREA, #681): `adTargetingParameters` is the whole exposé. Untouched mask → must-haves unconfirmed (E 2,0 per §Mask). D 2,0–2,5. Warm unknown if Gesamt == Kalt. **"Energieausweis: laut Gesetz nicht erforderlich"** is unbacked (the exemption is essentially Denkmal or <50 m²): a Low signal and a Denkmal hint for the Mietspiegel row.
- **Scam verdict on minimal/anonymous ads: the price direction decides.** Bait underprices; an offer inside or above the priceBar band and above the Mietspiegel refutes the bait reading → typically 1 Medium + 1 Low = Legitimate. Write the refutation out.
- **`AGENTS_INFO.rating` is portal-internal and friendlier than independent sites; `numberOfStars` is the REVIEW COUNT** (4,9 from 10 is thin). - **`AGENTS_INFO.name` can be the holding** (…Holding/Group/Invest + `verifiedBy: []`): search the Hausverwaltung arm at the same Impressum address (#638 "EB Group Holding" clean, EB IMMOBILIENMANAGEMENT ~1,6/5 → H 2,0). Corporate = low Eigenbedarf but high Instandhaltungs-/Erreichbarkeitsrisiko; next step: Ansprechperson, Reaktionsfrist, Übergabeprotokoll.
- **Rental that is also for sale** (orte page shows a Kauf exposé at the same address with the same `obj_cId`; #907: Kauf 170440518 at 799.000 EUR "bezugsfrei" since 01.09., rental since 06.10.): (1) harvest EA, "Baujahr laut EA", Hausgeld and the Aufteilungsplan PDF from the Kauf twin (Abgeschlossenheitsbescheinigung date settles § 556f, the WE number decodes the unit); (2) H ~2,5: a buyer can give Eigenbedarf notice straight after purchase, no § 577a Sperrfrist when the WEG split predates the tenancy; (3) next step 1 = "still for sale? Kündigungsverzicht/Eigenbedarfsausschluss in the lease". Not a "reposted with different prices" scam signal.

- **The same operative contact can appear under different registered firms** (T&C: Franz Schäfer, Geltow, contact under "Liane Berger" #388 and company #604): key Anbieter history on **phone/address**, not the company string. ScanHaus Marlow runs ≥3 Potsdam reps at Rudolf-Moos-Str. 9a (Juliane Rau, Stefanie Rau, Butros Yacoub) under one Impressum (R. Kossow & Levermann GmbH): score H per person.
