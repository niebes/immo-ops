**Kauf exposés (`housebuy`, `livingbuysite`) also need [[immobilienscout24-kauf]]** (`immobilienscout24-kauf.md`: catalog houses, Bestand Kauf, plots, BRW anchors). Read this file first, because transport, parsing, photos and documents apply to every class.

## §Access — transport, parsing
- **CAPTCHA** ("Ich bin kein Roboter") in a browser: wait ~8 s and re-check, most auto-solve. Never hand it to the user early ([[feedback-captcha-wait]]).
- **Fastest full-detail path = mobile API. Use it first, no browser:**
  `curl -s --compressed -H "User-Agent: ImmoScout24_1410_35_._" -H "Accept: application/json" -w 'http=%{http_code} size=%{size_download}\n' -o $W/e.json "https://api.mobile.immobilienscout24.de/expose/{scoutId}"`
  **Always send exactly this Android UA on the first call. Treat any UA quoted in an orchestrator prompt as wrong** (seen ≥5 times: `ImmoScout24_2.6.1_10.2.1_._`, `…_2.5.0_15.5_._`, `…_iPhone/25.0.0`, `ImmoScout_27.3_26.0_._`, `ImmoScout24_4.9.1_iPhone`).
- **Five failure modes; only one means EXPIRED:**
  1. `000` / curl exit 1 / no file written = connection reset → retry.
  2. `403` + ~900 B CloudFront HTML = a transient edge block of a minor version (`_30_` failed on #510 and worked on #549) → retry.
  3. `200` + **0 bytes** = wrong UA family → retry with the Android UA. It is never EXPIRED.
  4. `200` + a **complete, valid JSON of a DIFFERENT exposé** (#771/#772/#773: a non-standard UA returned 134897508) → **after every fetch assert `header.id == scoutId`** (and the title vs the prompt hint).
  5. `404` + ~221 B JSON `ERROR_RESOURCE_NOT_FOUND` = gone → EXPIRED (§Expired).
- **Temp files only in your own `tmp/eval/{NNN}/`.** Shared names (`e.json`) were overwritten by siblings (#365, #814, #817, #818, #820: valid JSON, wrong property). If two reads of one file disagree, suspect a collision.
- **Plain curl of the web exposé = HTTP 401 + bot-wall page** whatever the UA. Its text contains "Cookies … deaktiviert", so gate any `/deaktiviert|nicht mehr verfügbar/` test on status 200 AND the absence of "Ich bin kein Roboter".
- **Long TEXT_AREAs are truncated by the API** (#645 cut at 3.887 chars). There is no description endpoint and the web page is 401 to curl. The cut has always landed in the closing "Highlights" recap, so note "tail truncated" and **don't escalate to a browser for it.**
- **External sites:** on a TLS error with WebFetch, retry curl on the apex without `www` (#633). WebFetch ignores query params on some Amt geoportals.
- **orte address page — run it on every ad with a known street + Hausnr:** `curl -s --compressed -A "{Firefox UA}" -H "Accept-Language: de-DE" https://orte.immobilienscout24.de/adresse/{ort}-{plz}-{strasse-slug}-nr-{n}` (WebFetch 403, `atlas.` 301; sweep 3–4 neighbouring numbers when the Hausnr is uncertain). It gives (a) KI-generated building text (grep `erbaut|Wohneinheiten|Stockwerke|Geschätzte Miete`; the decade is optional and the amenity lines echo the live ad), and (b) the JSON of **live exposés at or near that address (verify each hit, see below), Kauf and Miete side by side**, with `@creation`/`@publishDate`/`@modification` (exact ad date: [[immobilienscout24-history]] §Dating; a parallel sale: §Anbieter). *Why:* #907's rental exposé gave no hint that the same flat was also for sale.
  - **Use `curl -L`:** since 2026-10 the short `…-str-nr-{n}` slug answers HTTP 308 (~47 KB stub) to the long `…-strasse-nr-{n}` slug; without `-L` the grep runs on the stub and finds nothing (#916, all four numbers).
  - **The KI building text can be flatly wrong on Denkmal conversions** (#915 Voltaireweg 6: "modernes Reihenhaus seit 2010, 1 WE, drei Stockwerke" for the 1879 Garde-Ulanen stable with 13 flats). Never take Baujahr or WE count from it when the exposé or a Denkmal source disagrees. *Why:* it would have moved the Mietspiegel row from bis-1948 to 2009–2012.
  - **The exposé ID set is not always per-address; sometimes it is a nearby-listings widget.** On #919 (Neuendorfer Anger 5/6/7) all three pages carried the same 16 IDs, the target among them. Before reading "also for sale" or a dup out of it, check each hit's own street + Hausnr (or that the ID set differs between neighbouring numbers). *Why:* a bare `grep expose/\d{9}` would have listed 15 foreign ads as "live at this address".
  - **Exposés with a withheld address (`obj_street: no_information`) are absent from the exposé JSON**, even when their text names street + Hausnr (#915). An empty sweep then neither proves the ad dead nor dates it; fall back to media-ID/PDF dating ([[immobilienscout24-history]] §Dating).

### JSON shape (parse `.sections[]` by `.type`)
- `header`: `id`, `publicationState` (`active`/`live` = live), `realEstateType` (`apartmentrent`, `houserent`, `housebuy`, `livingbuysite`), `isTenantNetwork`, `shareMessage`. **`header` can be absent** (#320), in which case read liveness from the `FRAUD_REPORT` URL's `publicationState=` param.
- `TITLE`, `MAP` (addressLine1/2, lat/lng, zipCodeShapes), `TOP_ATTRIBUTES` (Kaltmiete/Zimmer/Wohnfläche/Warmmiete, `REDUCED_PRICE`), `TAG_LIST`, `PRICE_INFO` (priceBar), `PRICE_RATING`, `FINANCE_COSTS`, `TRAVELTIME` (`isBlocked`), `RELOCATION`, `REFERENCE_LIST` (Preisentwicklung link, "Weitere Dokumente" PDFs, project landing pages), `AGENTS_INFO` (company, name, title, rating, `verifiedBy`, phoneNumbers, Impressum in `references[].url` `is24://imprint?text=`), `OBJECT_INFO` ("Scout-ID … | Objekt-Nr. …"), `contact` (`freemiumSettings`, `mailButtonState`, `callButtonState`).
- `ATTRIBUTE_LIST` (title "Hauptkriterien" / "Kosten" / "Bausubstanz & Energieausweis"): `{label,text}` or `{type:"CHECK",label}` = present. "Energieausweis: liegt vor" often comes without class/value (a Low signal).
- `TEXT_AREA`: Objektbeschreibung / Ausstattung / Lage / Sonstiges. Any of them can be missing, and a private ad can have none at all (#681).
- `MEDIA`: see §Photos. The top-level **`adTargetingParameters` (~51 keys) is the full field mask**, while `tracking.parameters` is a stripped ~18-key blob (§Mask).
- Parse with python3 `json.load`. Gotchas: **at least one section is an empty `{}` with no `type`**, so use `s.get('type')` or the dump dies mid-loop. `AGENTS_INFO.rating` can be missing entirely, which means no reviews (H ≈ 3,5 unknown), not a negative. Several `ATTRIBUTE_LIST`/`TEXT_AREA`/`REFERENCE_LIST` entries exist, so key them by `title`.
- **CiC-only quirks** (web page, fallback path): the redactor turns zero-padded dates (`01.08.2026`, Vonovia `DD.MM.YY`) into `[BLOCKED: JWT token]`. Match `/(\d{1,2})\.(\d{1,2})\.(\d{2,4})/` on `textContent` first, and fall back to splitting in-page and returning the parts. Scope keyword tests to `.is24qa-objektbeschreibung`/`-ausstattung-beschreibung`/`-lage`, **never `document.body`**. Page chrome and the "Weitere Einheiten" project sidebar fake Keller/Garten (`\bGarten(?!haus)`), **WBS** (#264: a sibling unit's "WBS 140") and **möbliert/auf Zeit** (#265: sibling studios) hits, so anchor blockers on this unit's h1 + its own text. Tenant-network pages have no `<dl>`, so read `body.innerText`.

## §Expired — EXPIRED detection and special live states
- **Mobile API 404 `ERROR_RESOURCE_NOT_FOUND`** = record gone → EXPIRED. Before filing, run a **control curl** on a known-live exposé with the same UA, to prove the path/UA still work and the 404 is listing-specific (#371). *Why:* otherwise an API/UA change mislabels a whole batch.
- **Web "deaktiviert" stub**: still HTTP 200 with h1/coarse address/m², but all criteria are null and the body says "Vor N Tagen deaktiviert" / "Angebot wurde deaktiviert" / "Dieses Angebot ist nicht mehr verfügbar". Match `/deaktiviert|nicht mehr verf[üu]gbar/i` (the generic "nicht gefunden" misses it) → EXPIRED, don't score the stub (#259, #260). Remember the bot-wall false match (§Access).
- **After a 404, rescue the text from `mapio.net/expose/{id}/`** (WebSearch `"{Straße} {Ort} {Objekttyp} mieten"`; curl works). It has the full description/Ausstattung/Sonstiges/Anbieter plus the posting date, which separates "let" from "bait withdrawn". See [[mapio-net]] (#733).
- **Stub exposé** (title `"s"`, description `"t"`, 0 photos, `publicationState: live`, full criteria table, named private Anbieter; #349): not EXPIRED, not an extraction glitch. Score from the criteria: D cap 3,0, must-haves unconfirmed, H 2,5, scam "Proceed with Caution".
- **Preview / not yet published** (200, "Adresse … erst nach Veröffentlichung", Anbieter hidden, "Bald verfügbar", 0 photos, criteria populated; #277): score it (D cap, H low), and the next step is to wait for publication. A "Fotocasa" string is a syndication artefact.

## §Tenant — Mieternetzwerk (tenant-posted) and private Nachmieter ads
Normal permanent rentals, not swaps ([[project-nachvermietung-not-filtered]]). **Exception:** a Suche line in the description tail ("Wir suchen eine 3-4 Zi Wohnung in …") makes it a swap → run the two-sided match (#340).
- **Detect:** `header.isTenantNetwork: true`. Corroborators: `TAG_LIST` id `TENANT_NETWORK` ("Nachvermietung ab {Monat}"), `AGENTS_INFO.title` "Aktuelle:r Mieter:in", the vorgeschlagen/Mietanpassung/Möbelübernahme notice. You are only *proposed* to the landlord → H ~3,0. Flag Möbelübernahme, and drop that flag when the photos show an empty flat.
- **Only `obj_totalRent` (warm) is real.** IS24 back-computes `obj_baseRent` = **exactly 70 %** of it and shows ±5 % bands ("Geschätzte Kalt- und Warmmiete"). Always compute the ratio. At 0,70 the Kalt and NK are arithmetic: no Kaution-legality check, and ask for the split (#552, #561, #612, #615). **The 70/30 split understates Kalt by ~15–20 %.** Reconstruct `totalRent − NK/m² × m²` as a band and test that against the caps and the Mietspiegel. Lead A with warm vs `max_warmmiete` (#676: derived 1.610 fit, reconstructed 1.920–2.050 broke all three caps). **NK evidence ranking:** stated split (a twin ad) > same-building rate from a sibling report > the city band 3,00–4,50 incl. Heizung. Name the tier (#694 derived 5,35 vs #761 stated 4,65).
- **"Die Miete wird sich eventuell anpassen" → quantify the re-let:** `m² × sibling ask + NK` against both caps. The best anchor is a same-street landlord ad in `data/listings.md`, `reports/` **or `data/pipeline.md`** (#745 → re-let still inside the caps, A 4,5). **Score A on the position within the Mietspiegel Spanne, not on budget headroom** (#735 at the Unterwert = 5,0 vs #746 at the Oberwert = 4,5). Only an under-Spanne rent has a legal ceiling absorbing the increase. Below the Ortsteil level = the old contract, not a bargain or scam signal (#614). **Above the Ortsteil level** (#747) flips the re-let into an opportunity (§ 556e only carries the Vormiete forward): −0,5 Mietspiegel, −0,5 over its own Ortsteil. In a **post-2014 quarter (§ 556f)** there is no ceiling at all, so the sibling gap IS the re-let number: −0,5, ask "bleibt die Kaltmiete?" first, and call § 556f an assumption while the Baujahr is unstated (#693).
- **Dates:** TAG_LIST month vs description date → take whichever is still future (both future → the description). Never score F off a past date (#560, #554). Both past on an active ad (#553, #562) → F 3,5, a staleness signal, "still free?" as next step 1. Not EXPIRED.
- **Title and description are IS24-generated from the form** ("Wohnen mit Charakter: 3-Zimmer-Wohnung in Potsdam"). An identical title is **zero** dup evidence (#736/#619, #768 vs #216). **The title's rooms/city can be wrong** (#562 "1-Zimmer" for 3,5 Zi; #557 "Brandenburg an der Havel" for Bornim). Use `obj_noRooms` and the geo cluster. Title + text agreeing is one field printed twice. The floskel text is not a scam tell. Prose m² vs `obj_livingSpace`: the field wins, so ask about it (#559). A one-sentence text can be the key fact ("Wir dürfen keine Nachmieter suchen", #614 → G 3,5, H 3,0).
- **Address resolution order:** (1) the description opening ("Diese Wohnung in der Peter-Behrens-Straße", #768) or a title that is only "Stormstraße 16" (#737), checked against `geo_ot`/PLZ; (2) the Telekom base64 leak (§Location); (3) PLZ only. The trio `TRAVELTIME.isBlocked` + addressLine1 "…erhältst du vom Anbieter" + `grep -c telekomInternetUrlAddition` = 0 → **unrecoverable, stop hunting** (#612, #618, #620): bracket the Mietspiegel over the plausible Baualtersklassen ("nicht bestimmbar") and anchor on evaluated Ortsteil comparables.
- **With a street:** `grep -ri "{Straße}" data/listings.md data/pipeline.md reports/` gives Baujahr, Verwalter, NK rate, house ask and amenity priors (#559 → #293/#361). A same-street report outranks KI text. **Without a report:** WebSearch `"{Straße} {Nr}" {PLZ} {Ort} Baujahr Energieausweis` (#561: presumed Platte = Neubau 2021 EEK B, a 2,7× swing), and/or the orte address page (§Access).
- A decoded address that is a special building (#557 = AWO Gemeinschaftsunterkunft) → data-integrity flag + contact Q1, not scam. **Unresolvable same-building dedup** (UUID, sibling on Immowelt = curl 403) → score as new with an "open identity question" section (#738 vs #666; identity keys in [[immobilienscout24-history]] §Identity).
- **Plain private Nachmietergesuch / private landlord ad** (`isTenantNetwork: false`, `obj_privateOffer: true`): real Kosten list, untouched mask (§Mask). `obj_baseRent` is the outgoing tenant's rent, and the new rent may appear only in prose (§Price). "Herr {Vorname} {Initial}", empty address, no phone → unresearchable, H ≈ 2,5 (§Anbieter).

## §Price — price fields and anchors
- **Ratio test `obj_baseRent / obj_totalRent` on every ad.** 0,70 = back-computed (§Tenant). **1,00 = no Warmmiete at all**: an empty NK field makes IS24 echo the Kalt as "Gesamtmiete"/"Warmmiete", while the row still says "Kaltmiete (zzgl. Nebenkosten)". Report warm as unknown + a band (2,50–3,00 EUR/m² incl. Heizung for older stock) against `max_warmmiete` (#713). Exact figures sit in `adTargetingParameters` when TOP_ATTRIBUTES shows ranges.
- **`PRICE_INFO.priceBar`** (similar band, overall band, `priceIndicatorPositionInPercent`) = the address-precise scam-price check. It can be missing (#552): then use the Mietspiegel bracket + the Ortsteil anchor ([[potsdam-mietspiegel]]), and without a band the "20 % below" High can't fire. **`PRICE_RATING` "Geprüfte Miete"/`FAIR_OFFER` is IS24's badge, not Bremse evidence** (#616: FAIR_OFFER at position 0,88). It is a label only.
- **Percentile vs Mietspiegel:** the band is Ortsteil-wide, so a building younger than its Ortsteil tops it without being overpriced (#561: 0,93 yet 26 % under its correct field). For A/Bremse the Baualters-correct field wins, and the priceBar governs only scam signals. **Converse:** typical/old building + above band + over Mietspiegel = a real overshoot → one step below the usual 4,5 (#625 → 4,0). A tenant ad above the band = "Bremse probably breached".
- **`REDUCED_PRICE` (`originalPrice`/`text`): divide the Kaution by BOTH.** It is often still 3× the OLD rent (#512 3,27×, #757 3,11×) → **G 2,0 categorically**, with the mitigation in prose. A re-derived one is legal (#740). The cut is evidence the old ask wasn't enforceable. **Contractual temporary cut** ("Einstiegsmiete", a "Besondere Mietkondition:" block in **Lage**; #569 steps up +645 EUR after the Schallschutz defects are fixed): grep Lage + Objektbeschreibung for `Einstiegsmiete|temporär|Mietreduzierung|Mietminderung|erhöht sich|Sonderkündigungsrecht`. Score A on `originalPrice` with a now/later table, D down for the named defect, G ~2,5.
- **Private Nachmietergesuch: `obj_baseRent` is the outgoing rent.** Grep `Aufschlag|Anpassung|Erhöhung|erhöht sich|Neuabschluss|Neuvermietung` and re-run caps/€/m²/Mietspiegel/Kaution on the announced figure (#568 +200 → the warm cap breached, A 5,0 → 3,5).
- **"Warmmiete" without heating:** `Heizkosten` 0/missing + "Heizkosten in Nebenkosten enthalten: Nein". `Etagenheizung` / `obj_heatingType: self_contained_central_heating` alone suffices (the tenant holds the gas contract; #532, #567). Report the printed figure + a labelled all-in: with an EA, `Endenergie × m² × ~0,11 EUR/kWh ÷ 12 + ~15`; without one, 12–18 EUR/m²/year for Altbau. Test it against `max_warmmiete`, and ask for the last two Gasabrechnungen. **Mirror:** `obj_totalRent` > Kalt+NK+HK by >±4 EUR = an unitemized position. Prove it by diffing a same-landlord sibling (#691 +54,70 vs 0/−4,20), use the higher figure, and ask which position (a Low flag, not scam).
- **"Nebenkosten" field > Kaltmiete = the lister typed Kalt + Betriebskosten into it** (#875: KM 1.832,93, "Nebenkosten" 2.199,52, Gesamt 2.295,99, "Heizkosten in NK enthalten: Ja"). Test: Gesamt − field = Heizkosten (96,47 = 1,00 EUR/m² × 96,47 m²), field − Kalt = BK (366,59 = 3,80 EUR/m²); a round per-m² result confirms it. Report the reconstructed split as a data-entry quirk (it reconciles to the euro), not a scam/padding signal. *Why:* read literally, NK = 22,80 EUR/m² and a nonsense warm rent.
- **Project cards quote another unit's price.** A search hit titled "{N} passende Wohneinheit(en): {Projektname}…" is an IS24 *project* card (`obj_projectId` set); its price is the project's "ab"/other-unit figure (#916: card 1.290, unit exposé 1.720 kalt). Score the live exposé, name the card price in the report, and add a contact question ("is the 1.290 unit still free?"). *Why:* scoring the card would have put 19,38 EUR/m² at 14,5 and passed the 18 EUR/m² cap.
- **Kaution ÷ 3 = Kalt** resolves Kalt vs Teilwarm and which of two conflicting ads is consistent.
- **Wohnfläche with Freisitze at 100 %** (#751 plan "Balkon (100 %)") breaks WoFlV (max 50 %, usually 25 %), so compute €/m² on the honest area. Below BGH 10 % it's leverage, not a claim.
- **"Energieausweis: laut Gesetz nicht erforderlich" on a rental** (Denkmal in text only, or a pre-1948 building in a Denkmalbereich): use the Potsdam Mietspiegel **`kein EA` row** as operative, with the A/B row as the landlord's best case (#582, #638). See [[immobilienscout24-kauf]] K2.
- **Havelland rents 2026:** Dallgow flats ~11,8–14,7 EUR/m², **houses ~100 m² ~18,95** (judge a Haus on the house anchor). **Mietpreisbremse in Havelland only in Falkensee, Brieselang, Schönwalde-Glien**, so for Dallgow: not applicable and no § 556g lever (#530).

## §Photos — captions, Grundriss, Block-D cap, amenity evidence
**Core rule: count real photos of the INTERIOR OF THIS UNIT, and decide it from the pixels, not from captions or `obj_picturecount`.**
- **Download:** take `MEDIA[].fullImageUrl` (skip `type: "AD"`) and swap `/format/webp/…` → `format/jpg`. Curl into the work dir, then Read (`dwebp` is the fallback). ⚠ The shell is **zsh**: unquoted `$var`/`set -- $p` loops don't split and save error bodies, so wrap them in `bash -c` (#795). `…png/ORIG/resize` can be a 25–45 MB PNG: PIL-thumbnail it before Read (full-res phone PNGs argue for authentic self-shot photos). For plans, never use `legacy_thumbnail/800x600`, which crops (#838). Use `…/ORIG/resize/1200x1600%3E/format/jpg/quality/80`. `obj_picturecount` counts slots, so dedupe by bytes.
- **Phone-original captions = real, no cap:** `YYYYMMDD_HHMMSS`, a 30-digit id, `image.jpg`, `IMG_####`, an iOS UUID, `WhatsApp Image YYYY-MM-DD at 0`, `IMG-YYYYMMDD-WA0000`, Samsung `YYYY-MM-DDHH.MM.SS…`, a bare number. Dated shapes timestamp the shot: months old = the flat may be empty (lever, no Möbelübernahme; #734). An old date shows an Altvertrag (#817).
- **…but a phone-shaped caption often hides a GRUNDRISS** (#735, #739, #741, #746, #568). Real photos are then 0, so the D cap fires (→ 2,5 with nothing else known). The plan is the **best amenity evidence**: printed "Loggia"/"Balkon" overturns `obj_balcony: n`, a drawn tub, a separate kitchen, a Durchgangszimmer, a windowless Bad. An in-unit "AB" is not a Keller. A plan also dates the layout (WBS-70 → 1971–1990; CAD + Loggia + 2 Bäder → post-2000). Plans move E, never D. Other plan captions: `OG`/`DG`/`EG`/`KG` (#680), `Bildschirmfoto …` (#772), a raw CAD filename (`FF26888_…`, #769). **AI-furnished plans without dimensions** ("Präsentiert durch Performer CRM", #861) are good for room count/layout, not m², and are no D-cap reason.
- **Real photo ≠ unit photo:** `BEISPIELFOTO` captions (#753), street/foyer-only `IMG_####`, or **upload fillers** (colour gradient, a desk keyboard; #855) → the zero-photo case. Not a scam signal (no property shown). **Genuine zero** (`MEDIA` absent or `[]`) + no Baujahr/condition/EA/plan → **D 2,5** (the cap is a ceiling; #621, #635).
- **Single exterior shot** → base −1,0, no full cap (#525 3,5 vs twin #231 4,5). Read it for the Baualtersklasse: Pfosten-Riegel alu facade, galvanised Gitterrost stair and Edelstahl-Netzgeländer = post-1990; young staked trees = quarter <10 y (§ 556f). **Old masonry + modern inserts** = a gutted conversion → the conversion-year row (#738, 1,5× swing). Facade evidence both ways: balconies everywhere → E 2,5 "likely"; Laubengang access decks → a negative prior, said in the prose (#675). **A single interior shot** can prove a negative (#619 Pantry-Kochnische), date the building (#556) or confirm a must-have (#553). Base from the frame, −1,0 for 1-of-N rooms.
- **Photo-rich ads: still open the odd-one-out caption** (#568: `IMG_5784` was the plan, and a Balkon was visible through the window). "No photo captioned X" ≠ X absent. Judge from the newest capture set.
- `.png` + ~0,46 portrait + black letterbox = the tenant's own screenshot, rotated 90° (#618). Not a scam tell. **Gallery photographed off a screen** (bezel, cursor; #802) = not the lister's images → Medium + H 1,5 + "Proceed with Caution" + an in-person viewing first. No D cap. Bait underprices, and #802 sat at the top of its band.
- **Numeric sort-index captions** (`0`, `1`, `99999` = append-last) are not renders. On Vonovia the trailing `99999` items are usually banners (#815: 7 = 5 real + 2 ads), so make a `montage` contact sheet. Numeric-ID captions on a *Kauf Planung* listing (`1555066-131917-1-g`) ARE catalog renders: the class decides.
- **ONE example-photo regex over all TEXT_AREA text + all captions:** `Muster|Beispiel|z\.\s?B\.|Referenz|Symbol|Visualisierung|ähnlich|tapezierfertig|unrenoviert`, plus stems `Musterfoto|Vergleichswohnung|baugleich|typengleich|Beispielwohnung` (captions truncate at **30 chars**, so use stems `Visualisierun|Musterwo|Digital-Home|Renderin|Symbolb|KI-generier`). **Grade by share:** a disclaimer sentence or a mostly-example gallery → D cap 3,0 on existing flats (#564 talyo, #748 "Musterfotos einer Vergleichswohnung" while captions were plain `IMG_6006…`). One labelled room among ≥5 real → no cap (#842). Vonovia puts "ACHTUNG: … Musterbilder" / "nur Musterfotos hochgeladen" at the **end** of the Objektbeschreibung (#566/#576/#586/#678/#679/#837) with "tapezierfertig … unrenoviert" (→ ~4–7 T own cost). Openly disclosed = exculpatory, so say it was refuted.

## §Mask — amenity flags (`obj_*`): when is `n` a fact?
- **Read `adTargetingParameters` (~51 keys), never `tracking.parameters` (~18 keys, no amenities)** (#619/#622/#623). A "missing key" means you're in the wrong blob. That supersedes the old #619-vs-#736 "absent vs present keys" split.
- **Untouched mask** = all flags `n`, zero positives, condition/interiorQual/pets = `no_information` (all tenant ads, most private ads). Every `n` is **unset, not absent**: score amenities from text/photos/plan, never fire "2+ must-haves missing = 1,0", and make them contact Q1 (#504 `obj_balcony=n` vs "• Balkon"). **E value:** no photo and silent text → 2,0 (#622). ≥1 real photo (a verification path) → 2,5 (#559). One must-have granted + one unconfirmed → 3,0 (#635, #741).
- **A deliberate `n` needs ≥2 `y`/CHECK positives on a commercial ad** (a real `obj_condition` alone isn't enough; #530), **and no other `n` refuted by text or title**. One refuted `n` voids the whole mask (#752 EBK itemised vs `n`; #756 title "neuer Einbauküche und eigenem Garten" vs `n`/`n`). The title can only refute, never confirm. With a curated mask a lone `obj_cellar=n` = missing (soften ~0,5 on a Neubau; #523). Absent-with-silent-text needs a corroborator (a second datasheet, a substitute like "Dachboden").
- **`n` + text grants it under a separate contract** ("separater Pachtvertrag" garden #525, Stellplatz "gegen Aufpreis", Keller "anmietbar") = met with a cost caveat, terms in G. (Golm Gartenpflege history makes an unclear Pacht a live risk.)
- `obj_balcony: n` + Ausstattung "Ausrichtung Freisitz: {West…}" = Wintergarten/Loggia, so the must-have is met (#678, ask whether it's glazed). `need_of_renovation` + a CHECK = exists, not working (#511 half-dismantled EBK): open the Küche/Bad photos and write "who completes it, by when". `maisonette` + "Etage N von N" = Dachschrägen probably inside the m², internal stair, no lift (#536).
- **Souterrain** (`half_basement`, #631): `obj_cellar: n` is REAL (Keller fails). C −0,5 (Aufenthaltsraum share unknown). Place it toward the Spanne **Unterwert**. "Wohnung/Archiv/Studio" = Wohnraum or Gewerbe? (a G question).
- `RELOCATION` links' `floor=0` = unset, not EG.

## §Size — m² and rooms (Block C): validate the typed fields
- **m² typo test (tenant/private typed fields):** EUR/m² = Kalt/m², NK/m² = (warm−Kalt)/m². **NK < ~2,00 EUR/m² indicts the m² denominator.** Test digit slips (180→80) against a real Mietspiegel band (#555: 180 m² reads 4,67 EUR/m² vs 10,50 at 80 m²). Carry the ambiguity in C (#555 C 3,5). Never substitute your hypothesis, never fire "20 % below Mietspiegel" on it, and put "Wohnfläche laut Mietvertrag?" as contact Q1.
- **One-directional:** high NK/m² with a normal Kalt/m² indicts the NUMERATOR (bundled Stellplatz/Strom/Möbel or padded Vorauszahlung, #621 5,79). That is a cost question, not an m² doubt.
- **m²/Zimmer too LOW with normal NK/m² → suspect `obj_noRooms`** (#675 70 m²/5 Zi = 14). C ~4,0 and "tatsächliche Zimmerzahl + Grundriss?" as contact Q1. Very low ratio + Laubengang → "Sonderwohnungsbau?" as a data flag, not scam. >40 m²/room on a plain flat is also a red flag.
- **Aspirational room count:** a private owner enters rooms the flat *could* have (#754 "4 Zi" vs text "auf Wunsch in zwei Zimmer teilen", `Schlafzimmer: 3` vs "zwei Schlafzimmer", plan shows 3). Grep `teilen|teilbar|abtrennen|Trennwand|auf Wunsch` and count the plan labels. Score the visible count in the header and the tracker `rooms` column.
- **The Grundriss is the referee on documented ads too:** door marks refute "alle Zimmer über den Flur" (#749: Küche + Zimmer 4 only through Zimmer 1). **IS24 `Badezimmer: 2` includes the Gäste-WC**, so check the plan before writing "two bathrooms".
- **The headline Wohnfläche can include the Balkonanteil (25–50 %) or Wohn- + Nutzfläche.** The architect's plan title block ("WOHNUNG 8 · 75,12 m² · inkl. Balkon 78,45 m²", #585) or the room label ("Balkon A: 10,19 m² / 50 %: 5,10 m²", #587) gives both. **Always sum the room schedule.** It can shift the Mietspiegel column at a band edge and **flip `max_price_per_m2`** (#587: 17,50 advertised, 18,57 on the interior → over the cap). Score A on the real one and name both.
- **Over-`max_m2` calibration** (the rubric only defines "under"): +25 % → C 3,0 (#744 150 m²), +50 % → C 2,5–3,0 (#555). Score the residual harm (NK, heating, furnishing). Don't mirror the under-size penalty, because A already carries the cost.

## §Lease — lease terms and hard blockers hidden in free text
- **No field exists for Staffel/Index/Mindestmietdauer/Kündigungsausschluss.** They sit in Sonstiges, the Objektbeschreibung tail or even **Ausstattung** (#752 Covivio "Indexmietenvereinbarung über 10 Jahre"; #564; #611). Grep **all TEXT_AREAs concatenated** for `Staffel|Index|Mindestmietdauer|Mindestlaufzeit|Mindestmietzeit|Kündigungsausschluss|Mietanpassung`: Index ~−1,0 in A (the whole A risk on a § 556f Neubau), Mindestmietdauer ~−1,0 in G. Staffel amounts are rarely given, so ask. *Why:* otherwise G = 5,0 on a locked lease.
- **"Zwischenvermietung bleibt vorbehalten" is Freibleibend boilerplate**, not a Zwischenmiete (#611). **`genossenschaft` always hits** via the "Kaution oder Genossenschaftsanteile" label (#627, #536). Absent `WBS|Wohnberechtigung` IS a reliable negative, and market €/m² is almost never WBS stock.
- **Mass-generated exposés (ZBVV etc.): structured fields beat the prose** (#627: text "ab 01. August" vs field 16.09; a "Küche" photo vs `obj_hasKitchen: n`). Contradictions go into contact questions, not scam signals.
- **möbliert/auf Zeit exist only in free text** (`realEstateType` stays `apartmentrent`; #647 Progenea). Grep TITLE + all text for `möbliert|auf Zeit|Mindestmietzeit|Höchstmietdauer|befristet|Untermiete|Zwischenmiete|serviced|all.?inclusive|furnished`. **A hit is not the verdict.** "teilmöbliert" is usually Möbelübernahme (#701). Cap ≤2,0 only with a real auf-Zeit marker (befristet/Zwischen-/Untermiete/Mietende, a Pauschalmiete without a Kalt/NK split, a hotel-style inventory: Kofferablage, Hosenbügler, rolled guest towels, "Welcome" decor). **A re-list can launder the term into "bezüglich der Mietdauer sind individuelle Absprachen möglich"** (#876 = #126, ohne-makler private flat: "auf Zeit" left the title, "1–12 Monate" became that phrase, the grep only hit "Mobiliar kann überlassen werden"). That phrase is an OPEN term, never unbefristet: carry the predecessor's stated term forward and decide from the gallery; Kaution < 3 NKM corroborates. *Why:* read alone, #876 would have been scored uncapped. Counter-signs: a clean split, **Kaution exactly 3,00 NKM**, a concrete Bezug, Keller/Stellplatz. If not capped: "§ 535 or § 549 Abs. 2 Nr. 1?" in G, and **remove the Möblierungszuschlag (~100–150 EUR partial) before the Mietspiegel check**. **A pure Höchstmietdauer without furniture** (#748 "24 Monate maximale Mietdauer") = a Zeitmietvertrag: G 1,5–2,0, no global cap. **§ 575 BGB** is next step 1 (no written reason = unbefristet; quantify the swing). It is also an Eigenbedarf hint → cap H.
- **Kaution field is free text** ("3-fache Miete": 3× Kalt legal vs 3× Gesamt illegal), so flag the ambiguity in G. **An outsized Kaution** (#854: 18.000 on 1.650 = 10,9 NKM, anonymous 0-photo private ad) is the advance-fee payload. `_shared.md` has no such signal, so override to "Proceed with Caution" explicitly (proposal in the footer).
- **Plural title + generic text** ("möblierte LUXUS Apartments") = a portfolio ad → a Musterwohnung viewing question.
- **Neubau pre-letting with only a Sonstiges application boilerplate** (locals Real Estate "Wohnen am Brauhausberg" #624/#628/#629): contract terms are ABSENT, not "none" → G ~4,5, never 5,0. The **Immowelt twin** listed "Mindestmietdauer 24 Monate" as a field → G ~4,1. Nice-to-haves are not credited. H ≤ ~4,2 (Vermieter unnamed). The TITLE carries Etage/rooms/orientation. "EA liegt zur Besichtigung vor" = normal here (Low, no EEK bonus). Objekt-Nr. `H{Haus}-{Etage}-{Whg}` decodes the unit. Show siblings' €/m² side by side. Bauverzug risk goes in F (~4,3), with "kündigen only after a written date". The landing page is in REFERENCE_LIST "Weitere Links".
- **Nachmieter as Eintritt in den bestehenden Mietvertrag** ("tritt in die bestehende vertragliche Mietregelung ein"): the Vermieter is unnamed → H ~2,5. No new contract means § 556d doesn't apply (ask whether a new one will be signed, which flips it). Next step 1: the contract + Nachträge. "Umzug ins Ausland zum {future date}" is not the "landlord abroad" signal.

## §Location — which channel to believe (Block B)
- **Search-result Ortsteil is an IS24 label, not a PLZ proof.** #649 "Grunewald" was Halensee (10711). On PLZ-scoped searches verify the PLZ from the live exposé.
- **Geo-tag can name a different MUNICIPALITY** (Makler reach optimisation). #389 was tagged Fahrland/Potsdam while both TEXT_AREAs said "Wustermark OT Buchow-Karpzow"; #214 (ohne-makler feed) was tagged Groß Glienicke but was Eichwalde. Always read the first line of Objektbeschreibung + Lage before trusting the Ort. A not-listed but not-excluded Gemeinde is no blocker: B down, "Gemeindezugehörigkeit?" as next step 1, and state the score at the advertised location. Disclosing the true Ort in the text is exculpatory, not a scam signal.
- **`obj_telekomInternetUrlAddition` (base64) leaks a withheld address** (`MAP` "Die vollständige Adresse … vom Anbieter", `obj_street: no_information`):
  `echo "$val" | python3 -c "import sys,base64,urllib.parse;print(base64.b64decode(urllib.parse.unquote(sys.stdin.read().strip())).decode('latin-1'))"` → `{"ort":…,"strasse":…,"hausnummer":…,"plz":…}`. **Decode as latin-1** (UTF-8 fails on umlauts, #376). The value can be truncated mid-base64, so decode what you can and corroborate with MEDIA/PDF filenames (`OZS020_Energieausweis` = ObstZüchterStr. 20). Report it as an Anbieter-entered hint, not a verified address. It is the broadband check-point the lister typed, so on a boundary property it can back the geo-tag rather than the truth (#389). **It loses to the TEXT_AREAs.** A downloaded facade photo can verify it on private ads. Absent on many tenant ads (§Tenant).
- **The Lage TEXT_AREA can itself be IS24-generated boilerplate** naming a wrong Ortsteil and non-existent transit (#568 "Nauener Vorstadt … S7" for Bornstedt; #854 "S-Bahn S7" for Bornim; #883 "direkte Anbindung durch die S-Bahn-Linie S7" for Brandenburger Vorstadt; the S7 ends at Potsdam Hbf). Tell: short, generic, no street/landmark, and it contradicts title/description. Take the majority of independent channels (MAP, `geo_ot`/`obj_regio3/4`, decoded Telekom, title, description). Never credit a transit line named only in generated prose.
- **When free text names a STREET, resolve the Ortsteil via a street directory** (`WebSearch "\"{Straße}\" {Stadt} {PLZ}"`). `MAP.addressLine2` and the `REFERENCE_LIST` "Preisentwicklung" geocode slug are both PLZ-derived guesses and can disagree with each other and the truth (#613 Julius-Posener-Str. = Waldstadt I, not Schlaatz/Teltower Vorstadt). The Preisentwicklung link is a price REGION, not the Ortsteil (#741). The street's naming date brackets the Baujahr, and "verkehrsberuhigter Bereich" suggests a 2000s+ layout.
- **Konzern boilerplate: Objektbeschreibung, Lage AND Ausstattung can describe a different project** (BUWOG/Vonovia group, #510 Brunnenallee 3A: text about Bornstedt/Tram 92/96 for a Brunnenviertel flat with Bhf Rehbrücke + Tram 91). The address fields decide (`MAP`, lat/lng, `RELOCATION`/`REFERENCE_LIST` deep-link params, the `geocodes=` path), then WebSearch the street. The BUWOG Ausstattung string mixes building tokens (`Spielplatz`, `Mehrfamilienhaus`, `Fahrradabstellraum`) with unit tokens (`Badewanne eingemauert`), so it's project spec. **The photo decides each unit-level amenity in both directions** (#692 shower only, #691 tub + shower). Log it as a data-quality ✗, not a scam signal.
- **`obj_street: no_information`**: read the Grundriss image captions. They can carry the Makler's internal key (`90864 Objekt Hege16 EG` → Hausnr 16, "Hege…"; #706). MEDIA captions on Kauf ads can leak the exact street too.
- **`obj_telekomInternetSpeed` (address-precise Mbit/s) is a scoreable Block-B negative.** ≤16 Mbit/s deserves the flag (#565: 6 Mbit/s in a prime location, and Mario works from home) → B −0,3 plus "check Vodafone Kabel / DNS:NET / Glasfaser for the address" before the viewing. ≥50 is unremarkable. `obj_telekomInternetAvailable: false` is a real con too.

## §Anbieter — Block H and scam context
- **`contact.freemiumSettings` (private ads):** `dateStarted`/`dateEnding`/`freemiumPeriodActive` = a 72–96-h free contact window. `dateStarted` ≈ (re)publication day. A window opened today + `verifiedBy: []` + no address/phone + first-name-initial ("Dominic H.") → **Medium** "new account, minimal profile" + H ~1,5–2,5. **The window alone is every private landlord's default, so it counts as the Medium only with the full cluster** (empty `phoneNumbers`, call button `inactive`, no address in the text, thin attributes). #625 had freemium but a real mobile, full address, EA and legal Kaution → Low, Legitimate. `duration` varies (72/96 h), so read it. A free 4-day test posting is the same signal. Put an active `dateEnding` in next steps as a deadline. ⚠ **`freemiumPeriodActive: false` with a past `dateEnding` ≠ dead or uncontactable.** Check `publicationState` + `contact.mailButtonState: active`. Never write a deadline that has passed, and `dateStarted` is then the RE-publication date (#760 → recycled-ad reading).
- **The EMPTY private exposé** (`picturecount 0` and no TEXT_AREA at all, #681): `adTargetingParameters` is the whole exposé. With an untouched mask, must-haves are unconfirmed (E 2,0 per §Mask; #681's original E 1,0 predates that rule). D 2,0–2,5 (below the cap). Warm unknown if Gesamt == Kalt. **"Energieausweis: laut Gesetz nicht erforderlich"** is an unbacked claim (the exemption is essentially Denkmal or <50 m²): a Low signal, and a Denkmal hint for the Mietspiegel row.
- **Scam verdict on minimal/anonymous ads: the price direction decides.** Bait underprices. An offer inside or above the priceBar band and above the Mietspiegel refutes the bait reading → typically 1 Medium + 1 Low = Legitimate. Write the refutation out.
- **`AGENTS_INFO.rating` is portal-internal and friendlier than independent sites. `numberOfStars` is the REVIEW COUNT** (4,9 from 10 is thin evidence). One WebSearch `{company} {Stadt} Erfahrungen Bewertungen` for every non-private Anbieter (provenexpert, jacasa, trustpilot). #511 EB IMMOBILIENMANAGEMENT: IS24 3,8/1.522 vs ProvenExpert 1,6/484 with 0 % Weiterempfehlung → H 2,0. A renovierungsbedürftig flat + a Verwaltung with maintenance complaints = compounding risk.
- **`AGENTS_INFO.name` can be the holding** (…Holding/Group/Invest + `verifiedBy: []`): search the Hausverwaltung arm at the same Impressum address (#638 "EB Group Holding" looked clean, while EB IMMOBILIENMANAGEMENT sits at ~1,6/5 → H 2,0). Corporate = low Eigenbedarf risk but high Instandhaltungs-/Erreichbarkeitsrisiko. Next step: Ansprechperson, Reaktionsfrist, Übergabeprotokoll.
- **Rental that is also for sale** (the orte page shows a Kauf exposé at the same address with the same `obj_cId`; #907: Kauf 170440518 at 799.000 EUR "bezugsfrei" since 01.09., rental since 06.10.). (1) Harvest EA class/Kennwert, "Baujahr laut EA", Hausgeld and the Aufteilungsplan PDF from the Kauf twin; its Abgeschlossenheitsbescheinigung date settles § 556f and the WE number decodes the unit. (2) H ~2,5: a buyer can give notice for Eigenbedarf straight after purchase, with no § 577a Sperrfrist when the WEG split predates the tenancy. (3) Next step 1 = "still for sale? Kündigungsverzicht/Eigenbedarfsausschluss in the lease". Not a "reposted with different prices" scam signal.
- **BLB (Land Brandenburg), public authorities:** empty `verifiedBy`/rating/address is meaningless, H 5,0 ([[immobilienscout24-kauf]] P6).
- **The same operative contact can appear under different registered firms** (T&C: Franz Schäfer, Geltow, as contact under "Liane Berger" #388 and as company #604). Key the Anbieter history on **phone number/address**, not the company string. ScanHaus Marlow runs ≥3 Potsdam reps at Rudolf-Moos-Str. 9a (Juliane Rau, Stefanie Rau, Butros Yacoub) under one Impressum (R. Kossow & Levermann GmbH). Score H per person.
- **A Bauträger exposé with a Provision is usually sold by a Makler; the builder may never be named** (#386: only a "Schaum-Logo" caption). G: builder solvency unverifiable. Next step: name the builder + Fertigstellungsbürgschaft § 650m BGB.
- **Private ad with IS24-generated prose** (#854 Bornim bungalow, 0 photos: the Objektbeschreibung paraphrased the checkbox fields, contradicted them on rooms (3,5 vs `obj_noRooms` 4 vs "Schlafzimmer: 1"), and invented an S7 connection): treat such prose as zero evidence, score from `adTargetingParameters`, and flag the conflict in C.
