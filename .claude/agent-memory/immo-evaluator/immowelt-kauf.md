# Immowelt (immowelt.de) — Kauf, plots, Fertighaus/Typenhaus, Zwangsversteigerung
Portal match: immowelt.de `/expose/{id}` Kauf exposés (`distributionType` BUY: houses, flats, plots, build offers, ZV), incl. Immowelt twins via aggregators. **Read [[immowelt]] first** (`immowelt.md`): access, liveness, payload parsing, Merkmale, energy, photos, location and identity apply to Kauf too.
**Read this file too when** the exposé is a sale (Kaufpreis, "Preis auf Anfrage", Provision für Käufer), a plot, a "projektiert"/Typenhaus build offer, or a Zwangsversteigerung.

Split out of `immowelt.md` on 2026-10-27 (size). Old references to "§Kauf-*" in [[immowelt]] mean the sections below. Sections: §Kauf-Price · §Kauf-Identity · §Kauf-Plots · §Kauf-BuildOffers · §Kauf-ZV.

## §Kauf-Price
- **`Preisdetails` / `sections.price` is a ready-made Block A:** Kaufpreis, €/m², `Provision für Käufer`, itemized Kaufnebenkosten, "Geschätzte Gesamtkosten".
  - **Count `price.breakdown.groups[].items`.** Fewer than the usual four (Notar 1,5 % · GrESt · Provision · Grundbuch 0,5 %) = the total is broken; recompute. #809 itemized only "Provision für Käufer (19 %)" = the MwSt rate printed as the commission (real `commissionFee` 3,3 % + MwSt = 3,927 %). Not chronic: #810 next day was correct, so don't discard the total pre-emptively.
  - The GrESt line uses the state rate (Brandenburg 6,5 %): check it matches the property's state.
- **`tags.hasBrokerageFee:false` is NOT proof of "provisionsfrei"** (#833: tag `false`, 3,57 % in commissionFee = 19.599 EUR).
  - Read `price.base.commissionFee` and the breakdown's `BROKERAGE_FEE` item verbatim: rate, when due, whether a same-rate seller contract exists (= § 656c split). #396 clean 2,38 %; #384's IS24 twin bound the Maklervertrag to the mere Exposé-Abruf at 3,57 %.
  - On Bauträger/Fertighaus ads (#798, #810) the printed 3,57 % is Immowelt's boilerplate: report it unconfirmed, §§ 656c/d BGB as a contact question. Same for the generic commissionFee "das Angebot kann … eine Provision beinhalten" next to "Provision für Käufer (3,57%)" (#976), and massa packages (#974: rep's IS24 ads 0 %, compute Kaufnebenkosten without it).
  - A Bauunternehmen selling its own land: ask whether the "Provision" is really Kaufpreis (then grunderwerbsteuerpflichtig) and whether a Bauverpflichtung makes it an einheitliches Vertragswerk (#809).
- **Price cuts are structured:** `sections.hardFacts.price.previousPrice` (e.g. "450.000 €") = the pre-cut price; in `innerText` it is a bare, unlabelled figure under the €/m² ("399.000 € / 2.934 €/m² / 450.000 €"). Read the field, pair it with `metadata.creationDate` for time-on-market (#946: −11 % after ~3,5 months). A negotiation lever, not a repost scam signal. *Why:* the bare 450.000 reads like a second price or an estimate.
- **The header €/m² is Kaufpreis ÷ Wohnfläche only.** If the prose names a larger Wohn- + Nutzfläche (e.g. a finished Keller), compute the effective €/m² too (#398: 30 % over the cap on the header figure, ~35 % under on the real one). Total cost, not sticker, goes against the budget cap.
- **`sections.priceComparison`** = `{data:{value, accuracy 1–5, low, high}, markerPosition, pricePerSqm}`. Quote `value` + `markerPosition` (the offer's percentile); the `low`–`high` band is enormous (#687: 1.773–6.313 in one Ortsteil). AVIV Angebotspreise = weak evidence; corroborate with ONE WebSearch anchor. The `innerText` "Preise in der Region" shows the band even on "Preis auf Anfrage" (#396 corroborated a BORIS floor); there `hasMainPrice:false` + `markerPosition:null` prove the price is missing, and `value` is the regional mean (#697).
- **"Preis auf Anfrage":**
  - `sections.mortgage.price` is a DUMMY feeding the "ab 4 € mtl. finanzieren" widget (#697: 1041). Never report it as the Kaufpreis. The fields that settle it: `hardFacts.price`, `price.base.main.value`, `priceComparison.hasMainPrice`, the visible Preisdetails.
  - **Recover the price from the IS24 Ortsteil results page** on the same stealth driver: `immobilienscout24.de/Suche/de/brandenburg/potsdam/{regio}/{ortsteil}/grundstueck-kaufen`, plain `{title, innerText}` eval, ~60 s (#762: "650.000 € · 832 m²" + the sibling half-plot + 9 comps in one call). Before any WebSearch.
  - **Never take a price from WebSearch answer text** (#762 got two confident, fabricated prices); use only result URLs.

## §Kauf-Identity
- **Bestand vs Neubau:** `metadata.isNewBuildProject` + `rawData.distributionSubType.buy` ("RESALE") + `propertySubType` + `energy.yearOfConstruction` (#687 refuted a suspected ScanHaus re-list in one line; 115 m² / ~420k collides constantly). On Typenhaus ads every one of these can lie (§Kauf-BuildOffers).
- **Portfolio sellers with baugleiche houses** (THE GROUNDS "FAHRLAND HOMES", Ref `14476-xx`): identical Baujahr/m²/rooms/EA is NOT a re-list (#796 vs #394, both live). Discriminate by `sections.key` Referenznummer (= IS24 `obj_objectnumber`), `plotSpace` (= `obj_lotArea`), the EA PDF's address + Registriernummer (`pdftotext`), IS24 `obj_rented`. A Grundriss header can name another unit's type plan (#796: three unit ids on one ad): never use it as the address. Fast cross-check: IS24 Ortsteil search on the driver → `indexOf(title)` for the expose id → mobile API for both ids.
  - **The Immowelt twin of an IS24-evaluated unit is a DUPE, not a re-list,** when Ref + EA-PDF filename (`{Straße Nr} Fahrland Bedarfsausweis.pdf`, in `innerText` "Weitere Unterlagen") + price match and the IS24 id still answers 200; `metadata.creationDate` settles it (#938 created 2026-08-13, before #590's IS24 evaluation, surfaced only after an `updateDate` bump). Stage `DUPE of #N` + `tracker_notes`, no report. Lister-set chips IS24 lacks (#938: Einbauküche, "Balkon" = the terrace) go into the note as questions; don't rescore. *Why:* the scan metadata looks like a new house.
- **Kauf Merkmale state negatives explicitly** ("Kein Keller", #397), unlike rentals.
- **Build-offer ads rotate under a NEW Online-ID/URL; the old exposé is deleted.** allkauf: Ref `4325-313-kw37-31940` (#798) → `4325-313-kw40-33874` (#913): the `{a}-{b}` prefix stays, only `kwNN-{serial}` changes; headline, Lage text, price, plot share and gallery byte-identical; the old one shows "Anzeige gelöscht". OKAL rotates via a re-dated Ref (§Kauf-BuildOffers). Dedup on headline + Ref prefix + price; the new row replaces the old (`tracker_notes` with `status: Expired` for the old #). *Why:* each rotation would otherwise get a full fresh evaluation.
  - **But one allkauf Gebiet posts SEVERAL packages per Gemeinde in the same kw:** same prefix + kw + rep is NOT a rotation when `plotSpace`, `livingSpace`, Ausbaustufe or price differ (#976 `3850-313-kw42-35633` vs #982 `…-35627`, Dallgow-Döberitz: 517 vs 689 m² plot, 142,23 vs 147,31 m², Pro Time vs Active Time). Both are live rows.

## §Kauf-Plots
- **Plot exposés have a shorter `sections` set:** no `energy`, no floorplans. Null-guard both, or the miner crashes and reads like a broken parse (#762).
- **Erschließung chips in `features.preview`:** `site-development-state` ("voll erschlossen"), `development-infrastructure` ("Strom, Gas, Telekommunikation, Wasser"), `with-view`, `plotSpace`, `availability` = the Block-D input when present. They are OPTIONAL (#809, #763: only `plotSpace` + `availability`): a prose "voll erschlossen" then has no structured backing → claimed-but-unverified, § 133 Abs. 3 BauGB (beitragsfrei?) in Next Steps. Photos are better evidence: #763 showed asphalt road, kerb, street lights and Hausanschlusskästen at the boundary → not Stufe 3.
- **Never shipped:** Flurstück, Lageplan, Katasterauszug → Next Steps. A sweep of `Bebauungsplan|B-Plan|§ 34|Innenbereich|Bauvoranfrage|Baugenehmigung|Flurstück` with 0 hits puts Baurecht on the bottom rung of the `_shared.md` ladder (#809).
- **A `HOUSE_FACADE` image on an unbebautes plot** shows a neighbour or reference house (#809).
- **Makler "Umgebungsfotos" captioned `description: "Quelle: {third party}"` are regional stock, not the plot** (#945 CETUS: Precise Resort, Angelfreunde, Förderverein Havelländische Malerkolonie; classifications meaningless). 0 plot photos (D unverified), no scam signal (sources labelled). Do read them for location: the landmarks (Handweberei Geltow, Malerkolonie Ferch, Petzow resort) put a "Potsdam West, 14471" plot at the Wildpark/Geltow lake edge, possibly across the city line in Schwielowsee. *Why:* `district` + polygon gave only the large Ortsteil shape.
- **Location:** out-of-area plots enter via a `city` collision (#763, [[immowelt]] §Location); street signs in the photos can settle it.

## §Kauf-BuildOffers — Fertighaus / Typenhaus / "projektiert"
Build offers are not existing properties; detect them before scoring.
- **Classic tells (#514, allkauf):** `Zustand: Projektiert`, "projektiert geplante …", `Provision für Käufer: Auf dem Grundstück möglich`, no EA (legitimate pre-completion), a bogus `modernisiert: {current year}`, Haustyp media (facade + Musterhaus + type plans), a Referenznummer with the calendar week (`…-kw30-…` = weekly-rotating ad, the named plot is indicative only).
- **Every structured field can claim existing stock** (#697 Mein Haus GmbH: "In bewohnbarem Zustand", RESALE, VILLA, `isNewBuildProject:false`, "frei ab sofort"). Tells that worked, cheapest first:
  1. `price.base.commissionFee`: "Grundstücke … nicht im Preis enthalten … Provision … auf den Grundstückspreis" (plot excluded + commission on the plot only = build offer; works off the search page too).
  2. A floorplan filename naming the Haustyp and an area ≠ `livingSpace` (`Bauhaus - 393 m² …` vs 347).
  3. Renders + a LOGO tile (0 real photos, no D cap: Neubau exception).
  4. Prose selling a service: Grundstücksservice, Grundrissplanung, a named Bausatz.
  5. A Referenznummer that is the creation date (`15052026`).
- **`energy.features` "Zustand: Projektiert" + "Haustyp: KfW 40" are reliable; RESALE/`isNewBuildProject:false` lie.**
- **Plot priced in notionally (#798, allkauf "Pure Home 1"):** `hardFacts.locationDescription` "Kalkulatorischer Grundstücksanteil: 300.000 EUR … Das Grundstück wird separat vom Eigentümer erworben". Subtract it for the house share; don't add a plot on top (double-count).
- **allkauf CAN include the plot: read `hardFacts.locationDescription` BEFORE the Erschöpfungs-/band test** (#976 Gebiet NORD, Dallgow-Döberitz: "Im Preis sind die Ausbaustufe Pro Time, die Bodenplatte und das Grundstück enthalten. Der Grundstückserwerb erfolgt unmittelbar vom Eigentümer."). Decide on the "im Preis … enthalten" sentence; "direkt/unmittelbar vom Eigentümer" alone only names the plot's seller. *Why:* 3.511 €/m² sat mid-band in the house-only band, so the band test would have inflated the all-in by ~150–200 T.
  - **Wording varies ("das mögliche Grundstück enthalten", #982) and the sentence can hide a price that doesn't add up:** cross-check same-kw siblings (§Kauf-Identity). #982 cost only +18.420 over #976 for +172 m² land (~43–65 T at BRW) and a higher Ausbaustufe, so its 3.515 €/m² also fits the house-only band. Plot inclusion + plot price share = contact question #1.
  - **Ausbaustufe scopes** (from `features.details.additionalText`): "Pro Time" = buyer does Trockenbau + Estrich; "Active Time für Ambitionierte" = allkauf does Estrich, Sanitär, Heizung, Elektro, buyer only Trockenbau. Cost the Eigenleistung in D/A.
  - **`additionalText` can contradict the "Zu allen Häusern gehört" boilerplate on heating** (#982 "Eine Luft-Wasser-Wärmepumpe ist nicht enthalten, stattdessen … Heizungsanlage gemäß KfW55"). The ad-specific text wins; a contact question, never an included feature. *Why:* the boilerplate alone (as #976 read it) credits a WP worth ~15–25 T.
- **massa haus (Sonsalla) kw batches cross-post here, sometimes Immowelt-first** (#974, #975): parcel keying, catalog anchors and the template lead price are in [[immobilienscout24-kauf]] K1. Here they carry the boilerplate "Provision für Käufer (3,57 %)" while the rep's IS24 ads show 0 %.
- **OKAL / DFH Handelsvertreter — plot included (#914, #956):**
  - **Plot IS in the price** (opposite of allkauf house-only). #914: "inklusive eines real vorhandenen Grundstückes" + `locationDescription` "keine Grundstücksdaten ohne Ihre Entscheidung" (undisclosed until you commit, so Block B is nominal). #956's prose was silent; tells were an OKAL banner "Inkl. Baugrundstück" (Bild 1, classified LOGO) and commissionFee "3,57 % des beurkundeten **Grundstückskaufpreises**". *Why:* without the banner the Erschöpfungstest reads "house only".
  - **Commission:** Immowelt's `BROKERAGE_FEE` still applies 3,57 % to the whole package (#956: 18.069 vs ~4–6k real), so "Geschätzte Gesamtkosten" is overstated; recompute on the plot share. § 656c does not cover an unbebautes Grundstück, so a buyer-only plot commission is legal.
  - **Ref = a re-dated rotating slot, two formats per rep:** `sb{YYYY-MM-DD}/{Haustyp}/{Ort-Kürzel}` (#914 `sb2026-09-25/Design9.2/Stü`, date = `updateDate`) and `{DDMMYYYY}{Rep-Initialen}{NN}` (#956 `07102026DH01`; `DHnn` is a per-rep slot counter, not a rotation marker). Dedup OKAL on Haustyp + Ort + price, never on Ref. *Why:* each re-date looks like a new house.
  - **One rep can post several Haustypen on ONE plot in the same week** (#956 Stadtvilla 10.2, 135,2 m², 450 m² plot, 506.148 vs #1039 `06102026DH07` Stadtvilla 10 mit Walmdach, 154,9 m², 453 m², 531.148; same Glindow Lage text): both rows stay live; link them via `tracker_notes` ("probably same/neighbouring plot"), ask which parcel. *Why:* each ad otherwise reads as an independent plot.
  - **Leistungsliste and Ausbaustufe live in `sections.features.details.additionalText`**: run the Erschöpfungstest there (#914 ended at Estrich / Sanitär-Rohinstallation / "Ausbau und Fertigstellung nach Absprache" = Ausbauhaus; #956 "Malervorbereitet … auf Wunsch Einzugsfertig").
  - **Gallery:** 2 type renders + ~11 show-house interiors captioned "Bild N", classified BEDROOM/KITCHEN/BATHROOM (not labelled Musterhaus) + a rep banner = not this house: Neubau exception, no D cap, Low "photos not of this property" only. Variant #1039: real captions ("Ansicht Wohnzimmer/Esszimmer/Galerie", "Grundriss Erdgeschoss/Obergeschoss", "QR-Code"), but interior renders of ANOTHER type (a "Galerie" render on a type whose plan has none): check renders against the plan before using them for C/E.
- **`aiEnrichments` "Keller" on build offers reads optional extras as included** (#914: from "Bodenplatte (optional Keller)"). Never score E from the AI chip here.
- **Silent about the plot (#810, the commonest case):**
  - **Erschöpfungstest:** a "Zu allen Häusern gehört" list enumerating items down to Steckdosen, with no Baugrundstück/Bodenplatte/Erschließung/Außenanlagen/Küche = house-only.
  - **Band test:** allkauf house-ONLY band **3.013–3.953 €/m²** (#422 3.013 · #709 3.246 · #514 3.155 · #367 3.586 · #419 3.921 · #377 3.953; #810 3.618 mid-band). Keep it updated; the only quantitative handle when the text is silent. Invalid once the Lage text states plot inclusion (#976).
- **Scoring:** all-in ≈ headline +20–30 % (Bodenplatte/Keller, Erschließung, Hausanschlüsse, Baugenehmigung, Außenanlagen, Küche, Ausbauhaus Eigenleistung), checked against the cap, not "Geschätzte Gesamtkosten". Flag the einheitliches-Vertragswerk GrESt question. Plot excluded → the `garten` must-have is not delivered (E 2,0) and Block B is nominal (a marketing catchment). No D cap for renders (`_shared.md` Neubau exception).
- **Galleries (allkauf):** bare "Bild N" captions, lying classification → download. #810: 0 real object photos (2 banners, 1 stock, 8 renders showing carport/terrace/fence/garden in no Leistungsposition). Galleries can mix house VARIANTS (#976: 5 renders of 4 allkauf types + a roof-shapes banner, all HOUSE_FACADE), and catalogue plans are type plans (5 rooms vs 4 advertised).
- **Sum the catalogue floorplans before scoring C** (#810: EG + OG = 146,26 vs 146,04 advertised, no Dachschräge, honest €/m²; #798: the OG Dachschräge cut ~7 m²).

## §Kauf-ZV — Zwangsversteigerung
- **Positive tests** (any one = a real ZV, all three on #508; none = the nav boilerplate is a false positive): (1) `document.title` contains "Zwangsversteigerungen"; (2) a Merkmal chip `Zwangsversteigerung`; (3) a `Zwangsversteigerung` label under the Kaufpreis in Preisdetails + "Versteigerung / Verkehrswert: {x}" in Sonstiges.
- **The headline is the Verkehrswert, not a Kaufpreis**: not into the tracker's price column. ZVG rules (5/10 and 7/10 floors, § 56 S. 3 no warranty, no Besichtigungsrecht, 10 % Sicherheitsleistung, Abt.-II rights) are in [[zwangsversteigerung-de]]. "Provisionsfrei, keine Makler-/Notarkosten" saves only ~1 % vs a provisionsfreien freihändigen Kauf.
- **Anbieter Argetra GmbH (Ratingen, 02102-711 711) is a ZV data publisher, not the seller.** It paywalls Termin/Amtsgericht/Aktenzeichen (free on zvg-portal.de). Its "BITTE … TELEFONNUMMER ANGEBEN" opener is lead capture: Block H, not a scam signal.
