# Semmelhaack (semmelhaack.de) — evaluator notes

Matches portal: **Semmelhaack**. Detail URL shape: `/vermietung/wohnobjekte/details-wohnobjekt/{id}/`.

## Extraction
- Plain server-rendered page. `document.body.innerText` returns everything **behind** the cookie banner without needing to click consent — no interaction required. Grab it and slice by field.
- **Address is the first line after "Zurück zur Ergebnisliste"** (e.g. `Baumschulenweg 21a, 25436 Tornesch`). Always read the PLZ here — the title never contains the city.
- Price block is under a `Preise` heading: Kaltmiete / Nebenkosten / Heizkosten / Warmmiete / Kaution (stated as "3 Nettokaltmieten"). Energieausweis + Baujahr follow, then `Objektbeschreibung`, then `Sonstiges` (Staffelmiete, Mietbindung, Vertragsausfertigungsgebühr, "Fotos sind Musteransichten").
- Gallery imgs aren't under a `.galerie`/`.gallery` class — a generic `img` count (~45) is not a real-photo count. **Real photos are the ones served from `api.semmelhaack.de/bilder/objekte/{id}.jpg` with a meaningful `alt` (Wohnzimmer / Bad1 / Zimmer1 / Ansichten…)** — filter on that host and de-dupe by src to get the true count (a 2012 Bestand flat had 30 `img` tags but exactly 5 real photos). Neubau quarters instead show "Musteransichten" (renders); that's expected → no Block D penalty. Bestand listings with real `bilder/objekte` photos must NOT be capped at D 3.0.
- **`Nutzfläche ca.` is Semmelhaack's label for the Wohnfläche** — it is not a Nutzfläche in the DIN-277 sense (some datasheets do say `Wohnfläche ca.`; both labels mean the same number). Verified via the IS24 cross-post, which shows the identical number under "Wohnfläche ca.". Don't dock Block C or hedge the size for it. **Why:** the wording invites a bogus "82 m² Nutzfläche ≠ Wohnfläche" caveat on every Semmelhaack report.
- **Grundriss: usually absent, but NOT always** — some listings publish exactly one `bilder/objekte` image whose `alt` is `Grundriss` (Obj. 70976, report #531). So the filter "host = api.semmelhaack.de/bilder/objekte" is not enough: **check the `alt` and exclude `Grundriss`/`Lageplan` from the real-photo count**, otherwise a zero-photo listing reads as "1 real photo" and the Block D 3,0 cap silently doesn't fire. A Grundriss-only listing = 0 real photos → cap D at 3,0 for Bestand and put "no photos" in the ✗ cons.
- **Official Exposé PDF: `https://api.semmelhaack.de/bilder/exposee/Exposee_{id}.pdf`** (linked from the detail page's anchors, same `{id}` as the URL/Objektnummer). Cheap second source — `curl` it, then `pdfimages -list` to count real photos and `pdftotext` for the full field set. Confirms in one call whether the missing photos are a page-render issue or genuinely absent (70976: PDF also had only the Grundriss). **Why:** settles "did the gallery just fail to lazy-load?" without a second browser pass.
- **House (DHH/RH) datasheets use the same `Nutzfläche ca.` label for the Wohnfläche and show `Etage: 0`** — neither means anything for a house. Their Ausstattung block lists only the fields that are *present* (Terrasse / Garten / Gäste-WC / Objektzustand / Bezugsfrei ab); **there is no Keller row even as a "Nein"**, so a missing Keller can only be inferred, never read off. Corroborate with the IS24 twin's `obj_cellar` before scoring the must-have as absent (#530: `obj_cellar: n` + no Keller row + "Dachboden ausgebaut" advertised as the storage → treated as absent, Block E 2,5).
- **Heizkosten "0,00 €" + "Heizkosten in Nebenkosten enthalten: Nein" on a house = the tenant signs their own gas contract** — the advertised Warmmiete then EXCLUDES heating. Add it back from the Energieausweis (kWh/(m²·a) × m² × ~0,11 EUR + Grundpreis) before checking `max_warmmiete`; #530 was 1.900 quoted vs ~1.980–2.025 real. **Why:** taking the quoted Warmmiete at face value understates the monthly cost by ~100 EUR on every Semmelhaack Haus.

## Cross-post to ImmoScout24 (Potsdam stock)
**Dedupe key = the Objekt-Nr., and it is the semmelhaack.de URL id.** `…/details-wohnobjekt/{id}/`
equals the IS24 `OBJECT_INFO` "Objekt-Nr.: {id}" / `adTargetingParameters.obj_objectnumber` exactly
(verified 63851 = Schneeballweg 14 Dallgow-Döberitz, report #530). Match on that instead of on
title/price when both channels reach the pipeline — it is exact, survives price edits, and settles
the "same flat or sister unit?" question the photos can't (see the Fahrland note below).
Potsdam-area Semmelhaack objects are routinely also listed as IS24 exposés with identical numbers. **Semmelhaack is the landlord channel → provisionsfrei, apply there**, but open the IS24 twin to fill fields Semmelhaack omits: Etage, Wohnfläche-vs-Nutzfläche confirmation, `Garage/Stellplatz`, `Garten/-mitbenutzung`, Energiepass-Ausstellungsdatum. IS24 has no bot wall on these (no CAPTCHA seen). **Why:** Semmelhaack's own datasheet silently drops Stellplatz/Etage that materially move Blocks C/E.
- Watch for internal contradictions between the datasheet and the free-text Objektbeschreibung (`Etage: 0` vs. "im Untergeschoss"; "Terrasse: Ja" vs. "ein großer Balkon"). Neither side is authoritative — flag as a viewing question rather than picking one.
- **`Etage: 0` is Semmelhaack's default-empty value, and it propagates into the IS24 twin as `obj_floor: 0` — so on IS24 it looks like a real EG datum.** Same class of bug: `obj_lift: n` on a listing whose gallery literally contains a photo of the lift tableau. On Semmelhaack stock, **the Objektbeschreibung + Grundriss + photos outrank every structured field** (#698, Obj. 60177: fields said EG/no lift, text+plan+photo said 1. OG with Personenaufzug serving −1…3). **Why:** taking `obj_floor`/`obj_lift` at face value mis-scores Block C/E and contradicts the flat's own floor plan.
- **The Grundriss image caption is the unit's identity key** — IS24 caption `whg-1.07_71,50m2_1.og_web`, and the plan sheet header repeats it in print (`1. Obergeschoss  Whg. 1.07  ca. 71,50 m²`) plus the street in the top-right corner. That "Whg. {n.nn}" is what lets an **address-less tenant ad be matched to the landlord ad**: #594 (Kleinanzeigen, no address, no Baujahr) named "Whg. 1.07" from its own floor-plan photo and thereby resolved to Obj. 60177 / IS24 113017311 (#698) — same flat, Vormiete 875,00 kalt / 1.085,00 warm vs. the landlord's re-let at 900,00 / 1.200,00. Use it *before* the Warmmiete rule above; the Warmmiete changes between tenant ad and re-let, the unit number does not. ⚠ The plan sheet's street header can name the **neighbouring house number** (60177: sheet says "PASTOR-MORITZ-STR. 5", listing + door plaque say 7) — template reuse, not a provenance flag, but ask at contact.
- **A tenanted Semmelhaack unit ships ZERO interior photos**: the gallery is Hinteransicht / Straßenansicht / Treppenhaus / Aufzug / Grundriss (5 images, identical set on semmelhaack.de and the IS24 twin). The formal 0-photo Block-D cap does not fire (4 non-Grundriss images), but the "neuwertig" claim is unverified → dock D ~0,25 and say so in the cons. Look for a private re-list of the same flat on IS24 — it usually carries the camera-original `IMG_*` interiors (#698: twin 170310996 had 10).
- **Rules sweep is cheap and usually clean:** `curl` the semmelhaack.de page and grep for `staffel|mietbindung|wohnberechtigung|WBS|vertragsausfertigung|provision|befrist|index|musteransicht`. Obj. 60177 returned 0 hits on all of them — that is the evidence for Block G 5,0, so run it rather than assuming either way.
- **Two machine-readable fields settle the Etage/Warmmiete gaps without opening the IS24 twin — both live in the inline `ddata = [{…}]` JSON of the Leaflet map script** (plain `curl` reaches it; strip `<script>` tags *after* grepping, not before):
  - `"gesamtmiete": 1200` = the **Warmmiete**, which the visible Preise block never prints (it shows Kaltmiete / Nebenkosten / Heizkosten separately). Use it to cross-check `Kaltmiete + NK + Heizkosten` and to verify a private Nachmieter ad's stated warm figure.
  - Each image object carries `art` (`Bild` / `Grundriss`) and `bezeichnung` — and the **Grundriss `bezeichnung` encodes unit + m² + floor**, e.g. `whg-1.07_71,50m2_1.og_web` (Obj. 60177). That is the *only* reliable Etage source when the datasheet says `Etage: 0` and the Objektbeschreibung says "im 1. OG" — and the unit number (`1.07`) is what lets you match a private Kleinanzeigen ad's floor-plan photo to this exact flat. Also use `art` to do the Grundriss-exclusion for the real-photo count in one pass instead of parsing `alt` attributes.
  *Why:* on #703 (Obj. 60177 = Kleinanzeigen 3495849124 = #594) `gesamtmiete` 1.200 + `whg-1.07_71,50m2_1.og` matched the private ad's warm 1.200 / 71 m² / 1. OG / "Whg. 1.07" floor plan exactly — that quartet is what proved it was a repost of an already-evaluated flat rather than a fourth Fahrland unit.
- **The `bilder/objekte` photos can be from a SISTER UNIT, not the advertised flat** — on the Fahrland Zweifamilienhaus (Obj. 66108, `Etage: 0`) the "real" photos showed a Dachgeschoss flat (Dachschrägen, empty, Balkontür) plus a "BEISPIELHAUS" render; the free-text "großer Balkon" on an EG flat is the same copy-paste. **So a photo mismatch never disproves that a private Nachmieter ad is the same flat** — dedupe on the numbers instead: an exact **Warmmiete** match plus m² + Etage + Garten/Terrasse/Stellplatz is decisive (Kleinanzeigen 3475159992 "3,5 Zimmer Fahrland, ca. 1.370 € warm" = Obj. 66108 = report #516; the extra 0,5 Zimmer is the Hauswirtschaftsraum the tenant counts). The tenant ad adds an **Ablöse** ("Küche muss übernommen werden") and a hard move-in date that the landlord channel doesn't have → route to Semmelhaack. **Why:** without this, the sloped-ceiling photos read as "different unit" and the flat gets scored twice.

## The dominant quirk: nationwide → out-of-area discards
Semmelhaack lists **nationwide**, mostly Schleswig-Holstein / Hamburg / Meck-Pomm / Niedersachsen. The vast majority of forwarded listings are **300+ km from Golm/Potsdam → DISCARDED (location hard blocker)**. Recurring out-of-area PLZ seen: 25436 Tornesch, 21493 Schwarzenbek, 25335 Elmshorn, 23845 Itzstedt, Garbsen/Hannover, Heide/Itzehoe/Brunsbüttel, Tessin/Güstrow. Also frequent: **commercial** units (Büro/Lager/Praxis) → discard, and occasional **WBS-required** → discard.
The Potsdam-area quartiers worth keeping: City-Quartier Potsdam, Fahrland, **Neu Fahrland
(Gärtner-Schmidt-Str., DHH-Zeile Bj. 2002 — Obj. 63860 = report #589, 4,2/5)**, Eiche. **Why:** confirms the location on-page before scoring; the caller's metadata says "location unverified" precisely because Semmelhaack is nationwide.
**Semmelhaack also holds BERLIN stock** — e.g. 13591 Berlin-Staaken/Spandau (Obj. 70976, #531). Berlin is not on the rental search's `preferred`/`acceptable` list but also not excluded → **score it, don't discard**: Block B 2,0–2,5 per the Staaken precedent (#288, #250, #531), no hard-blocker cap, and say "out of area" prominently in the summary. **Why:** the "nationwide → discard" reflex above is only right for the 300 km SH/HH stock; Berlin objects are 15–25 km from Golm and deserve a real score.
